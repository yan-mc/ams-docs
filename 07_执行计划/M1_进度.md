## 启动器 v0.1.2 能力

- 环境卡片：Windows/CPU/内存/GPU/Python/Node/FFmpeg/Git/磁盘/AMS 数据目录，支持刷新；
- Gateway 卡片：读 `AMS_HOME/runtime/ports.json` + token，TCP 健康检查，显示版本/任务数；启动（spawn gateway venv）/停止（taskkill 进程树）；5s 自动刷新；
- 组件卡片：内核（ams-harness 是否构建）、音乐插件源码、Gateway、音源库（`AMS_HOME/voices` 目录数）；

## 插件 0.2.0 能力

- `/ams/api/*` 双凭据：机器 Bearer（Gateway token，常量时间比较）；浏览器短时 HttpOnly+SameSite=Strict cookie（Host 内存、30min、≤128）；session 签发校验 loopback Host + 同源 Origin/Referer + Sec-Fetch-Site；
- `GET /ams/api/jobs/{id}/events` SSE 透传（15s keepalive、Last-Event-ID）；Client EventSource + 指数退避重连 + 降级 2s 轮询；
- 验证：无凭据 401、跨站 403、同源 session 200、SSE 11 事件 terminal=succeeded、首页 200、bundle 含 EventSource。
