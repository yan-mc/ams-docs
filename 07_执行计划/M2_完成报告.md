## 5. 安全与限制

- 现有签名密钥是 **dev demo key**（`examples/keys/`，私钥不入库，公钥内置启动器）；正式发布必须换生产密钥；
- GitHub 仓库已全部私有，release 资产需要认证；M2 的匿名更新路径改为本地 feed；公网部署在 M3；
- 组件安装只负责“下载/解包/校验到 components 目录”；插件激活仍需 DSH plugin add/安装器后续接入；
- 内核整包/portable runtime 未打包（M3）；
- 没有代码签名证书，安装包在 Windows 上会提示未知发布者（内部测试可接受）。

M2 的“可分发 + 可更新”链路已具备可重复的构建、签名、校验和本地安装验证；M3 在此基础上做内核/服务整包、公网更新服务和正式签名。
