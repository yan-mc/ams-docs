# M0 环境自检报告

> 时间：2026-10-19 21:0x｜范围：本机 Windows 开发环境（只读检测，未安装/修改任何东西）

## 1. 结论

本机可以开始 M0，但**缺 Node.js / pnpm / Rust / uv / ffmpeg**；Python 3.12、Git（含凭据管理器）、winget、NVIDIA 驱动齐全。建议先用 winget 安装工具链，再进入 M0.1/M0.2。

## 2. 已具备

| 项 | 值 |
|---|---|
| OS | Windows 11 专业版 build 26300 |
| Git | 2.55.0.windows.3；credential.helper = manager（已登录凭据可用） |
| Python | 3.12.10（用户级）；另有 RVC 整合包 Python 3.9.13、GPT-SoVITS 3.9.25 |
| GPU | NVIDIA RTX 4080 Laptop，**12,282 MiB 显存**，驱动 610.88 |
| winget | v1.29.380（可用它装工具链） |
| 磁盘 | C 213GB / D 398GB / E 559GB / F 399GB 可用 |
| nvidia-smi | 可用 |

## 3. 缺失（M0 前置）

| 工具 | 用途 | 建议安装 |
|---|---|---|
| Node.js 24.x（或 22.19+） | DSH fork / 插件构建（pnpm workspace） | `winget install OpenJS.NodeJS.LTS` 或 24.x |
| pnpm 11.x | monorepo 依赖管理 | `corepack enable` 后 `corepack prepare pnpm@11.28.5 --activate` |
| Rust stable + cargo | 启动器 Tauri2 | `winget install Rustlang.Rustup`；需 VS Build Tools（MSVC） |
| VS 2022 Build Tools（C++ 工作负载） | Rust/Tauri Windows 编译 | winget/Visual Studio Installer |
| uv | Python 后端环境管理 | `winget install astral-sh.uv` 或官方脚本 |
| ffmpeg/ffprobe | 音频处理/验证 | `winget install Gyan.FFmpeg`（或由启动器组件管理） |
| gh（可选） | 建仓/Release 自动化 | `winget install GitHub.cli`（当前未装；也可用 git push + 网页建仓） |

## 4. 本机 Python 与后端

| 运行时 | 版本 | 可用性 |
|---|---|---|
| 系统 Python | 3.12.10 | ✅ 可跑 Gateway/工具；**无 torch** |
| RVC runtime | 3.9.13 + torch 2.0.0+cu118 | ✅ 可跑 RVC 推理/训练、MSVC 验证；不用于新开发 |
| GPT-SoVITS runtime | 3.9.25 + torch 2.6.0+cpu | ✅ 仅旧包 |

结论：新服务用独立 Python 3.12 环境（uv 管理），不与旧整合包混用。

## 5. 需要修正的设计假设

- **显存**：此前文档按“16GB 级”估算，实际为 **12GB**（12282 MiB）。影响：RVC 训练/分离/合成需按 12GB 收紧 batch/并发；pymss 大模型需分块/降 batch。已在 M0 计划中标注。
- **VST3/虚拟声卡**：需要额外组件，M0 只做检测与安装引导，不阻塞。

## 6. 建议的一键安装命令（需用户确认后执行）

~~~powershell
winget install OpenJS.NodeJS.LTS
corepack enable
corepack prepare pnpm@11.28.5 --activate
winget install Rustlang.Rustup
winget install astral-sh.uv
winget install Gyan.FFmpeg
winget install GitHub.cli   # 可选
~~~

安装后执行 `node -v && pnpm -v && rustc -V && uv --version && ffmpeg -version` 复核。

## 7. Git / GitHub

- 本机 `git config --global user.name/user.email` **为空**，M0 第一步需设置（建议与 GitHub 账号一致）。
- 凭据管理器已配置（credential.helper=manager），首次 push 会弹登录；`gh` 未安装，可用网页建仓 + git push，或安装 gh 后 `gh auth login`。
- 仓库规划见 `06_方案设计/05_工程与发布/Git备份与发布流程.md`。
