### 2.4 关键发现：faiss index 在非 ASCII 路径下静默失效（【事实】）

- 现象：RVC runtime 的 faiss（Windows AVX2 wheel）**无法打开含中文的路径**：`faiss.read_index("F:\ai歌曲\...\manbo.index")` → `RuntimeError: ... could not open ... No such file or directory`；RVC `pipeline.py` 第 309-315 行 `try: faiss.read_index(...) except: traceback.print_exc(); index = big_npy = None` → **index 被静默忽略，index_rate 不生效**。
- 判定：不是文件损坏——用 `faiss.deserialize_index(np.frombuffer(open(path,'rb').read(), dtype=np.uint8))` 成功解析出 ntotal=44,750 / d=768；用 `subst X:` 映射为纯 ASCII 盘符后 `faiss.read_index("X:\\work\\manbo.index")` 也成功。
- 影响：00 §6 规定 voices 文件夹名允许中文（如“曼波”），因此**产品 Runner 不能直接依赖 RVC 原生路径加载 index**。
- 采用方案（已在 `rvc_smoke.py` 实现并验证 fallback_used=1）：monkeypatch `faiss.read_index` → 失败时 Python 读字节 + `faiss.deserialize_index`。备选方案：① 把 index 复制/链接到纯 ASCII 缓存路径；② 进程启动时用 subst/短路径映射。三种方案均记录在 `experiments/README.md`。

### 2.5 其它 RVC 集成注意点（【事实】/【推断】）

| 注意点 | 说明 |
|---|---|
| cwd 必须是 RVC 根目录 | `.env`、`assets/weights`、`assets/hubert`、`assets/rmvpe`、`ffmpeg.exe` 均按相对路径解析 |
| .env 需显式路径 | python-dotenv 的 `find_dotenv()` 在脚本模式下会从脚本所在目录向上找；需 `load_dotenv(dotenv_path=RVC_ROOT/".env")` |
| 模型名必须是 `<name>.pth` | `get_vc` 直接拼 `weight_root/sid` |
| index 自动发现不可靠 | `get_index_path_from_model` 只在 `index_root=logs` 目录里找；需传显式 `--index` |
| sid 是 int | `vc_single` 第一参数是说话人 id（0），不是模型名 |
| 输出是 int16 | pipeline 末尾 `*32768 → int16`；写文件前必须 /32768 归一为 float，否则会当作 int 值直接写导致爆音（本脚本已处理） |

> 本机实测显存 **12,282MiB**（非 16GB）；RVC 实测峰值 1.3GB，SCNet CPU 实测与显存无关。以下 pymss 建议 = 官方默认 + 本次实测/文档推断的保守值，**GPU 实测后需回填**。

| 任务 | 模型（体积） | 建议 batch | chunk / overlap | 预计显存【推断】 | 说明 |
|---|---|---|---|---|---|
| 人声（首选） | `bs_roformer_voc_hyperacev2`（275MB） | 1–2 | 默认 480000 / 24000（5%） | 2.5–4GB | 12GB 余量充足 |

| 4 轨（最快/最稳） | `scnet_checkpoint_musdb18`（40MB） | 1–2 | 485100 / 363825（配置默认） | 1.5–3GB | CPU 亦可用；本次已跑通 |
| 4 轨（均衡） | `model_scnet_ep_36_sdr_10.0891`（204MB） | 1 | 默认 | 2–4GB | — |
| 4 轨（Demucs） | `HTDemucs4`（80MB） | 1 | 默认 chunk/segment | 2–4GB | — |
| 6 轨 | `HTDemucs4_6stems`（52MB） | 1 | 默认 | 3–5GB | guitar/piano 质量一般 |
| 去混响（轻） | UVR-DeReverb 系列（121MB） | 2 | window 512 | 1–2GB | VR 架构 |

| 项 | 建议 |
|---|---|
| 参数（params） | `{input_path, model_name:"manbo.pth" 或 voice_id 映射, index_path?:string, f0_method:"rmvpe", f0up_key:int, index_rate:0..1, protect:0..1, rms_mix_rate:0..1, filter_radius:0..7, resample_sr:0|16000..48000, is_half:bool, device:"cuda:0"|"cpu", output_format:"wav", wav_bit_depth:"PCM_24"}` |
| 进程要求 | 用 RVC 自带 runtime（Python 3.9）；**cwd=RVC 根目录**；env：`weight_root/index_root/rmvpe_root/outside_index_root`（或显式 dotenv 路径）；`PYTHONDONTWRITEBYTECODE=1`；TMP/TEMP 指向 AMS_HOME/cache |
| 关键补丁 | **faiss 非 ASCII 兼容**：启动时 monkeypatch `faiss.read_index`（失败→读字节+`deserialize_index`），否则中文 voices 路径下 index 静默失效（§2.4） |
| 进度 | RVC 无进度回调：按阶段映射 load_model 5% → preprocess/npy 15% → f0 40% → infer 40–90%（按音频长度估算）→ save 100%；产物 JSON 写入实测 `npy/f0/infer` 秒数 |
| 取消 | Runner 子进程注册 kill 回调（Gateway 杀进程树）；RVC 单次推理不可中断，取消=终止进程并清理半成品 |
| 错误码 | `RVC_ENV_MISSING` / `RVC_MODEL_NOT_FOUND` / `RVC_INDEX_FALLBACK`（警告）/ `RVC_CUDA_OOM`（降级 f0=pm 或 CPU）/ `RVC_FAILED` |
| 产物 | `wav`（40k/48k 单声道）+ `meta.json`（模型/参数/耗时/rtf/显存）；路径写 `projects/<id>/vocals/` 或任务目录 |
| GPU | 注册 `gpu=True`；实测显存需求 ~1.3GB，12GB 下可与其它小模型共享，但按 Gateway GPU 锁串行 |

### 5.2 `separate.pymss`（pymss 分离，GPU/CPU）

| 项 | 建议 |
|---|---|
| 参数（params） | `{model:string, inputs:string[], stems?:string[], inference_params:{batch_size,chunk_size,overlap_size,use_tta,standardize,normalize}, output_format, target_sample_rate?, device:"auto"|"cuda"|"cpu", model_dir, download_missing:bool, source:"modelscope"|"huggingface"|"hf-mirror", auto_degrade:bool}` |
| 进程要求 | 独立 venv（Python 3.12 + torch 2.7.1；GPU 用 cu128，CPU 用 cpu wheel）；`PYMSS_MODEL_DIR=AMS_HOME/models/pymss`；服务由 Gateway 拉起、127.0.0.1 + token |
| 进度 | 用 pymss `progress_callback(done_seconds,total_seconds,message)` → Job progress%；保存阶段单独上报；产物事件含每 stem 路径/采样率/时长 |
| 取消 | 默认「杀服务进程树+重启」（M0）；M1 改为任务级子进程隔离（与插件方案 §9.1 一致） |
| 错误码 | `SEP_MODEL_NOT_FOUND/DOWNLOAD_FAILED/LOAD_FAILED`、`SEP_OOM`（触发降级序列）、`SEP_DECODE_FAILED`、`SEP_CANCELLED` |
| 产物 | 每 stem wav/flac/mp3/m4a + `manifest.json`（模型/参数/rtf/vram 峰值/输入 sha256），路径 `projects/<id>/stems/<stem>/` |
| GPU/CPU | `device=auto`：有 CUDA 用 GPU（注册 `gpu=True`）；无则 CPU 降级（注册时按参数决定队列，或统一 GPU 队列内选择 CPU 资源） |
| 模型缓存 | AMS_HOME/models/pymss 与启动器组件 `catalog.models` 共用；首次下载需用户确认阈值（默认 5GB） |

### 5.3 公共建议

1. **后端服务独立运行时**（00 §3）：RVC 服务（py3.9）与 pymss 服务（py3.12）各一个进程，互不污染。
2. **产物 meta 统一字段**：`engine{name,version,torch,device}`、`timings{load,infer,rtf}`、`vram_peak_mb`、`params`、`warnings[]`（含 index fallback）。
3. **路径兼容**：RVC 相关产物/索引路径优先放纯 ASCII 缓存目录（或用 deserialize 补丁）；pymss 对路径无此限制。
4. **GPU 锁**：两个任务类型都属显存型，统一走 Gateway GPU 队列；实测 RVC 1.3GB / pymss（GPU 待测）可据此设置显存预估字段 `vram_estimate_mb`。
5. **日志脱敏**：本次实验日志含用户本地路径，接入后按 00 §12 脱敏。

## 7. 风险与待办

### 7.1 风险

| ID | 风险 | 影响 | 缓解 |
|---|---|---|---|
| R1 | faiss index 在非 ASCII 路径静默失效（已实测） | 换声音色变差且**无报错**，用户无感知 | Runner 层强制 deserialize 补丁或 ASCII 缓存路径；结果 meta 写 `index_used` 并在降级时 warning |
| R2 | RVC 整合包依赖 cwd/相对路径/旧 torch 2.0 | 集成脆弱、升级困难 | 用独立 `ams-svc-rvc` 封装，固定启动契约（cwd/env/参数）并加回归测试 |
| R3 | pymss GPU 路径未实测（cu128 3.05GiB） | 显存/RTF/兼容性未知 | M0.7 后续按 §3.4 安装并补测；产品安装器需支持大组件分段下载 |
| R4 | CPU 回退很慢（RTF 0.5–0.95） | 无 N 卡用户体验差 | 默认 GPU；CPU 仅小模型/降级并明确提示预估时间 |
| R5 | 模型权重许可不明（SCNet/Roformer 社区权重） | 商用/分发风险 | 不内置权重、按需下载；模型卡标注来源与许可（延续插件 02 方案） |
| R6 | 选段影响指标（drums 近静音） | 误判模型能力 | 复测多个选段；报告中标注选段信息 |
| R7 | 耗时波动（37s→20s） | 预估不准 | 预热模型/缓存、以第二三次稳定值做基准 |
