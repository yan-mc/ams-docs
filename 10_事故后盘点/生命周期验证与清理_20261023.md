## 6. GitHub 多账号问题

- 本机有两套 GitHub 凭据：`yan-mc` 与 `x-access-token`；系统 helper 是 GCM，用户 helper 是 store
- 原因：GCM 在 host-only 凭据下会询问用哪个账号
- 处理：按官方 multiple-users 文档，把项目默认账号固定为 `yan-mc`：
  - `git config --global credential.https://github.com.username yan-mc`
  - 六个项目仓库另设 repo-local 同名配置
- `GCM_INTERACTIVE=never git ls-remote` 对 ams-release、ams-launcher 均成功，不再弹窗
- 未删除 `x-access-token` 凭据；如确认它是遗留 CI token，可再执行 logout 清理
