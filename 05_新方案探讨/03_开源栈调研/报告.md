### 3.2 RVC 官方 2.3.260718 关键事实（本轮最有价值的更新）
依据 `raw/readmes/RVC_Changelog_EN.md`（官方 `docs/en/Changelog_EN.md` 快照）、`raw/readmes/RVC_README.md`、`raw/footer_feeds.json`（release atom）：
- **2026-07-23**：分离后端由 **UVR5 替换为 PyMSS**，且支持推理中中断分离；输入音频加载/重采样尽量走 GPU；修复实时变声开启输入/输出降噪时的 CUDA Graph 报错；修复 Windows 训练进程 libuv 兼容性。【事实】
- **2026-07-18**：数据特征提取/训练/index 构建**可中断续跑**；自动探测 GPU 决定推理模式与精度；实时变声 GUI 支持 **CUDA Graph**，官方在 RTX 4090D 实测算法推理延迟最高 **4.7× 加速**（GPU 利用率 20–30%）；新增 **FCPE** 音高提取；单卡训练**不再用 DDP**；底模不变但修了若干影响音质的 bug。【事实】
- **发布资产**（同一 release 页）：Nvidia <50 系包、**Nvidia ≥50 系包（CUDA 12.8）**、**AMD/Intel 包（DirectML/CPU）**、**RVC Real-Time VST2/VST3 插件（Win64）**，并提供中国镜像下载说明。【事实】
- **训练数据**：README 明确“推荐至少收集 **10 分钟**低底噪语音数据”；底模用约 50 小时 VCTK 训练，无版权顾虑。【事实】
- 安装矩阵：RTX 50 系需 CUDA 12.8 torch（`requirments_cu128_py312.txt`）；50 系以前 CUDA 11.8；CPU/AMD/Intel 用 `requirments_cpu_py312.txt` + Windows DirectML / Linux CPU。【事实】

**【推断】** 对本机（RTX 4080 Laptop 16 GB）：官方 2.3 是唯一同时覆盖 RTX 50 系与 AMD 的 RVC 主线；其“官方实时 VST2/VST3”把变声器插件从“调 Python GUI”降级为“加载一个 VST”，是四条产品线里**最省集成成本**的路径；同时 PyMSS 内置让“歌曲换源”的分离→换声流水线少一个外部依赖。

### 3.3 为什么“主 RVC + 零样本旁路”是最优组合【推断】
- **质量/可控性**：RVC 针对**特定音色**微调后相似度、咬字稳定性仍优于零样本；数据要求 10 分钟级，本机 16 GB 可训 48k v2。
- **零样本旁路**：用户“先试听再决定炼制”时用 MeanVC2 / Qwen3-TTS /（可选）Seed-VC 权重，无需训练；但 Seed-VC 仓库已归档，长期维护风险高，只做隐藏选项。
- **SVS 不同路线**：若要“歌词+曲谱→演唱”（不是换声），应该用 **DiffSinger（Apache-2.0）声库 + OpenUtau（MIT）**，与 RVC 互补（见 §6.3）。

### 4.2 延迟与工程要点
- **RVC 实时**：核心参数是 `block_time`/`crossfade_length`/`extra context`（本机心月套件实测配置为 **block_time 0.15 s / crossfade 0.08 s**，F0=FCPE，CUDA/DirectML/CPU 三后端，来自 `03_心月套件` 只读分析）。【事实（本机配置）/推断（默认值可调）】
- **CUDA Graph**：RVC 2.3 实测最高 4.7× 算法加速（RTX 4090D），GPU 利用率仅 20–30% → 4080 Laptop 上“实时 + 低占用”可期。【事实+推断】
- **设备层**：Windows 上推荐 **WASAPI 独占/共享 + 虚拟声卡**（VB-CABLE / VoiceMeeter / MagicLine）；若宿主是 DAW/VST，直接用 RVC VST 插件可绕开虚拟声卡与 Python 进程。【推断】
- **模型格式**：RVC `pth + index(faiss)`（index 可选，index_rate 控制“像不像”）；ONNX 导出（RVC 有 ONNX 导出 tab，VCClient onnx 版可跑）；**GGUF**（audio.cpp 打包 F16/Q8，可跨 NVIDIA/AMD/Metal/CPU）。【事实】
- **风险**：实时链路对 **音频设备切换/采样率不一致** 很敏感（pymss-ara 专门做了 streaming resampler 处理源-宿主采样率不一致，可借鉴）。【事实（pymss-ara README）/推断（RVC 同理需处理）】

## 6. 训练 / 音源炼制（流程、数据要求、自动校验）

### 6.1 四条炼制路线对比

| 路线 | 代表项目 | 训练数据要求 | 产物 | 本机 16 GB 可行性 | 用途 |
|---|---|---|---|---|---|
| **RVC 微调**（歌声/语音换声） | RVC 2.3.260718 | 官方推荐 **≥10 分钟**低底噪；1–30 分钟即可出可用模型 | **.pth**（G/D）+ **.index**（faiss，可选） | ✅ 48k v2 训练可跑【推断】 | 歌曲换源、变声器音色 |
| **GPT-SoVITS 微调**（TTS 音色） | GPT-SoVITS v2Pro / V5 | 零样本 **5 s**；少样本微调 **1 分钟起**；高质量建议 10–60 分钟（含参考文本） | GPT **.ckpt** + SoVITS **.pth**（+ SV embedding） | ✅ v2Pro ~4–6 GB 显存【推断】 | 配音、TTS 插件 |
| **DiffSinger 声库**（SVS，唱词+曲谱） | DiffSinger + MakeDiffSinger | 需 **MIDI/曲谱 + 歌词 + 人声**；MFA 强制对齐；通常 1–2 小时标注数据起步【推断】 | **ds** 声库（供 OpenUtau/DiffScope） | ✅ | 歌曲换源的“歌姬”路线、填词 |
| **零样本**（免训练） | Qwen3-TTS（3 s）、IndexTTS-2.5、Seed-VC（归档）、MeanVC2、GPT-SoVITS 5 s | 1 段 3–30 s 参考音频 | 无（引用权重） | ✅ 推理即可 | 快速试听/预览 |

### 6.2 RVC 训练管线（官方 2.3，基于 Changelog/README/WebUI 事实【事实+推断步骤名】）
1. **素材准备**：干净人声（建议先分离+去混响，见 §7），切成 5–15 s 片段（RVC 自带 slicer，silence 检测）。
2. **预处理**：重采样到目标采样率（32k/40k/48k）→ 切片 → **F0 提取**（pm/harvest/dio/rmvpe/fcpe，2.3 新增 **FCPE**）→ **HuBERT 特征**（v1 256 维 / v2 768 维）。
3. **训练**：v1/v2 生成器+判别器；2.3 起**单卡不再用 DDP**、特征/训练/index 可**中断续跑**；total_epoch 最大 1000（默认 20）。
4. **建 index**：faiss 索引（index_rate 决定推理时“检索训练集特征”的程度，越高越像但可能失真）。
5. **抽小模型**：从 G_*.pth / D_*.pth 中导出推理用 *.pth。
6. **校验**：训练集/验证集分别推理，检查相似度、音高偏差、破音/电音（见 §6.4）。

### 6.3 GPT-SoVITS 微调与版本选择（本地 wiki 原文【事实】）
- **架构**：GPT（AR 语义 token）+ SoVITS（VITS/扩散）+ 参考音频/文本 + SV 声纹。
- **版本选择（官方 wiki 明确）**：
  - **v1/v2/v2Pro 系列**：适合**音质一般**的训练集（压缩重、16k 以下频段缺失、混响/底噪较多也能出可接受结果）。
  - **v3/v4/v5**：相似度/情绪更强，但**音色更偏向参考音频而非训练集**，对训练集质量要求高。
  - **v2Pro**：性能超 v4、成本与速度接近 v2（133M+77M）；**v2ProPlus** 152M+77M；**v5** 基于 v4 蒸馏 SoVITS 扩散 + 新 vocoder，语言支持同 v4（中英日韩粤），**推理约 4× v2**。
- **训练流程（s1/s2）**：数据切片 → ASR（faster-whisper / FunASR）打标 + 校对 → s1 训练 GPT → s2 训练 SoVITS → 导出 GPT_weights_v*/xxx.ckpt + SoVITS_weights_v*/xxx.pth（可参考本机既有包：Mualani-e15.ckpt / Mualani_e8_s1336.pth）。
- **零样本旁路**：5 s 参考音频直接推理（无需训练），适合“先听效果”。
- **V5 现状（重要）**：README 的 V5 Release Notes 指向**分支 cuda_graph_accel_v5**（最后提交 2026-10-08，Windows 需要 triton-windows），**尚未合并进 release tag**；建议一期用 v2Pro 正式版，V5 作实验后端。【事实】

### 6.4 自动校验工具链（数据集“质检”建议）

| 环节 | 推荐工具（版本/许可） | 指标/阈值建议【推断】 |
|---|---|---|
| ASR / 歌词转写 | **faster-whisper 1.2.1（MIT）**、**FunASR 1.4.16（MIT，已迁 modelscope 组织）**、whisperX（MIT，词级时间戳） | 中文 CER < 5%；英文 WER < 5% |

### 7.2 pymss 生态（本地只读调研，与 task-4 交叉验证）
- **pymss**（MIT）：catalog 模型名直接调用（如 bs_roformer_voc_hyperacev2），缺模型自动下载（默认 ModelScope，可换源）；**workflow 文件**可把“分离→去混响→ensemble”串成流水线（input: split.other 引用上一步输出）；**ensemble** 可融合多模型人声；**server** 提供动态加载/模型目录浏览/下载/WebUI；**插件系统**（register_capability/register_node/register_cli）。
- **pymss-studio**（Tauri 桌面端，**AGPL-3.0**——若我们要二次分发其代码需注意 AGPL）：批量分离、模型下载、音轨编辑与混音导出。
- **pymss-ara**（**VST3 + ARA**，Windows-first）：在 DAW 内直接分离整轨，带流式重采样、背景进程推理、stem mute/solo、模型浏览器——**“DAW 内分离”的现成参考实现**。
- **pymss-mnn**：MNN C++ runtime + 离线转换工具（移动端/无 Python 部署）。
- **注意**：pymss 本身 MIT，但**catalog 里的具体模型权重许可能不同**（如部分社区 Roformer 模型带 NC 限制），分发时需按模型逐个核对。【事实（多许可生态）+推断（逐模型核对必要性）】

### 7.3 结论【推断】
- **“一键本地分离”后端 = pymss**：catalog+自动下载+workflow+事件回调，天然适合被插件当子进程/HTTP 服务调用；MIT 可商用。
- **嵌入式/轻量 = audio-separator**（PyPI，模型复用 UVR 生态）。
- **SOTA 与自训练 = MSST**；**GUI 体验参考 = UVR 5.6**。
- 流水线建议：输入 → (可选)去混响 Roformer → BS/Mel-Roformer 人声/伴奏 → (可选) karaoke/chorus 模型拆主唱/和声 → 输出 stems + 质量指标。

## 8. 统一音源包格式草案（UVP v0.1，Unified Voice Pack）

### 8.1 设计目标
1. **一个音源 = 一个目录**，可训练端产出、推理端消费；跨 RVC / GPT-SoVITS / DiffSinger / ONNX / GGUF 多后端。
2. **声明能力**（singing / tts / realtime_vc / svs），推理端据此选后端并 fallback。
3. **数据来源与许可可追溯**（声音授权、底模许可、数据集统计）——应对深度合成合规与版权风险。
4. **可完整性校验**（sha256）与**可升级**（format_version + 兼容规则）。
5. 与现有格式**零损耗互操作**（RVC pth+index、GPT-SoVITS ckpt+pth、DiffSinger ds、ONNX、GGUF 都作为后端文件原样存放）。

### 8.2 目录结构（建议）
    voice_pack/
    ├── manifest.json            # 唯一入口（见 8.3；含 mode/hash/license/backends）
    ├── manifest.sig             # 可选：ed25519 签名（包分发时）
    ├── models/
    │   ├── rvc/<name>.pth
    │   ├── rvc/<name>.index
    │   ├── gptsovits/<gpt>.ckpt
    │   ├── gptsovits/<sovits>.pth
    │   ├── diffsinger/<voicebank>/...      # .ds 声库目录原样
    │   ├── onnx/<name>.onnx
    │   └── gguf/<name>.gguf
    ├── refs/                    # 零样本/参考音频（.wav + 同名 .txt 转写）
    │   ├── ref_zh_01.wav
    │   ├── ref_zh_01.txt
    │   └── ref_zh_01.json       # 时长/语言/情绪/来源
    ├── preview/

### 8.4 训练管线如何产出（契约）
1. **采集/清洗**：切片 + 去混响 + 去噪 → validate_dataset（§6.4）产出 training/dataset.json（含时长/SNR/DNSMOS/ASR 指标）。
2. **训练**：按后端跑（RVC train / GPT-SoVITS s1+s2 / DiffSinger MakeDiffSinger），**冻结配置快照**到 training/config.<backend>.json，日志到 training/log.txt。
3. **评测**：跑 eval（ASR 回译 WER、相似度、DNSMOS、f0 RMSE、RTF）→ training/metrics.json。
4. **打包**：pack.py --backend rvc --backend gptsovits --voice-id … 生成 manifest.json + 拷贝文件 + 计算 sha256 + 写 license/。
5. **发布**：可选签名 manifest.sig；分发前运行 uvp-validate（schema + hash + 许可字段必填）。

### 8.5 推理端如何选择（策略建议【推断】）
    请求(kind, language, latency_budget, hardware)
      → 过滤 backends: 具备 capabilities ∩ kind
      → 过滤硬件: vram_mb ≤ 可用显存；platform 匹配
      → 过滤实时: 若 latency_budget < threshold，仅保留 realtime-able（rvc/meanvc2/onnx/gguf）
      → 按 engine_preference 排序 + 最近成功/失败评分（熔断）
      → 命中：加载该 backend；未命中：降级到 preview（试听样本）并提示“需炼制”

- **歌曲换源**：固定 kind=singing → RVC 优先，fallback = DiffSinger 声库（若包内有）。
- **变声器**：kind=realtime_vc → RVC realtime / MeanVC2 / ONNX-GGUF；无实时后端时禁用该音源。
- **TTS**：kind=tts → GPT-SoVITS（有微调）> Qwen3-TTS 零样本（有 refs）> 系统默认 TTS。
- **缓存**：按 (voice_id, backend_id, sha256-first8) 缓存已加载模型，避免频繁 IO。

## 10. 推荐组合

### 10.1 三条产品线（一期落地）

**A. 人声分离插件（最低风险，先做）**
    pymss（MIT，子进程/HTTP，workflow）
      → (可选) dereverb_* Roformer 去混响
      → BS/Mel-Band Roformer 人声/伴奏
      → (可选) karaoke/chorus 模型拆主唱与和声
      → 输出 stems + 质量指标（SNR/DNSMOS）
    备选嵌入：audio-separator（MIT）；模型来源：MSST/MVSep 权重 + UVR 5.6 模型库

**B. 变声器插件**
    首选：RVC 官方 2.3.260718 实时 GUI（CUDA Graph）→ 封装为独立后端进程
    推荐形态：RVC 官方 VST2/VST3（Win64）供 DAW/宿主加载（一次集成，长期收益）
    备选：VCClient 2.1.4-alpha（cuda/dml，RVC+Beatrice，REST API）作外部应用
    零样本旁路：MeanVC2（Apache-2.0，流式）；(隐藏项) Seed-VC 权重（已归档）
    虚拟声卡：VB-CABLE / VoiceMeeter（仅非 VST 场景需要）

**C. 歌曲换源插件**
    pymss 分离（人声/伴奏/和声）→ RVC 2.3 歌声模型（48k v2）换声
    → 可选：修音（pyworld 音高/时值编辑）、混音（pedalboard 隔离进程）、
    母带（matchering 隔离进程 或 pyloudnorm+ffmpeg loudnorm）
    → 导出工程（内部 JSON → dawproject）/ 导出成品 wav

**D. 音源炼制插件（把上面的“模型”变成资产）**
    数据集质检（faster-whisper/FunASR + WhisperX + DNSMOS + SNR + 切片）
    → RVC 训练（歌声/说话）与 GPT-SoVITS 微调（TTS）二选一或都训
    → 自动评测 → 打包为 UVP（manifest + backends + training + license + hash）
    → 注册到音源库；推理端按 kind/capability 选择
    可选：DiffSinger 声库训练（SVS）；零样本参考音频包（Qwen3-TTS/IndexTTS）

- **性能回归**：V5/V2Pro 等新版本改动大，需保留“老版本后端”回退开关与 A/B 评测。
