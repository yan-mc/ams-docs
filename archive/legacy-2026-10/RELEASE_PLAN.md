# AMS Studio 工程进展与正式验收发布计划

日期：2026-10-25  
基线：feed 2042；setup 2,438,343 字节；当前安装 F:/AMS-Studio；源码根 F:/Deepseek_harness/AI音乐处理/08_项目代码。

## 一、总体判断

功能完成度约 90%，发布完成度约 65%，正式验收完成度约 60%。

当前不是“功能原型”，而是可日常使用的本地工作站；但仍不是可无条件交付给新用户的正式稳定版。

正式发布必须同时满足：

1. 干净 VM 可安装；
2. 覆盖升级保留 data；
3. 卸载保留 data；
4. Kernel/Gateway 生命周期可控；
5. 核心链路全量回归；
6. 无 P0/P1 阻断缺陷；
7. feed/setup/文档/版本一致；
8. 数据安全边界可验证；
9. 性能/稳定性达到最低门槛；
10. 发布包可复现。

## 三、模块逐项计划

### 1. 启动器/安装器

现有：

- Tauri 启动器、组件安装、端口黑名单重试；
- 组件 feed/setup；
- 原地升级保留 data。

未完成：

- 干净 VM/干净目录安装；
- 卸载保留 data 实测；
- 静默安装 /D 目标未验证；
- 安装失败回滚；
- 下载中断恢复；
- 启动项/桌面快捷方式策略。

计划：

1. 在隔离 Windows VM 或干净目录做全新安装；
2. 验证组件下载、校验、安装、启动 Kernel；
3. 覆盖升级，确认 voices/projects/config 不变；
4. 运行卸载器，确认 data 保留；
5. 重新安装并恢复可用；
6. 记录 setup/feed/hash。

验收：

- 新 VM 30 分钟内可用；
- 无 C 盘 AMS data 写入；
- 升级/卸载不丢用户数据。

### 2. Kernel/DSH 生命周期

现有：

- 启动器启动/停止 Kernel；
- 端口重试；
- 当前会话 watchdog。

未完成：

- 系统级常驻；
- 崩溃自动恢复；
- 多实例保护；
- 日志轮转；
- UI 不可用时的明确提示。

计划：

1. 明确“桌面应用”策略：启动器打开时由启动器监管；
2. 增加心跳文件和超时；
3. Kernel 退出自动重启，带退避和次数上限；
4. 启动器退出行为写清楚：保留还是停止 Kernel；
5. 可选：注册登录启动/计划任务，但必须可关闭。

验收：

- 手动杀 Kernel 后 30 秒内恢复；
- 不产生多实例；
- 失败时 UI 有明确错误，不白屏。

### 3. Host 桥接

现有：

- 鉴权、session、jobs、SSE、artifact、project、voice、dataset 路由；
- 项目函数已内联，避免模块加载问题。

计划：

- 路由级自动化测试；
- 统一错误格式；
- 并发/大文件上限；
- 工程 steps 异步终态专项；
- 日志不含 token/用户 Key。

验收：

- 401/403/404/422/500 行为一致；
- 大文件上传不阻塞 UI；
- token 不出 Host。

### 4. 音乐 UI

现有页签：

项目、实时变声、音色库、TTS 批量、音源炼制、数据集、评测器、混音、分离、换源、MSVC、TTS。

问题：

- 单 bundle，不是独立插件；
- 页面自动化只覆盖表单；
- 空态/失败态/长任务提示不完整；
- 部分页面信息密度高。

计划：

1. 逐页验收清单；
2. 统一加载/空态/错误态；
3. 播放器、A/B、任务队列可访问性；
4. 页面级性能检查；
5. 是否拆分插件单独决策，不阻塞正式功能。

验收：

- 每个页签有明确入口、空态、错误提示；
- 关键操作 3 步内完成；
- 1440×900 和 1920×1080 可用。

### 5. Gateway

现有 10 类任务：

convert.msvc、convert.rvc、separate.pymss、train.rvc、tts.synthesize、dataset.prepare、evaluate.audio、mix.master、ping、mock.long。

计划：

- 任务恢复/重启测试；
- 队列并发/GPU 串行；
- 任务保留与清理；
- 失败错误码统一；
- API 压测；
- 健康检查指标。

验收：

- 重启 Gateway 后 queued/running 状态可解释；
- GPU 不并发抢占；
- 取消能在 5 秒内释放。

### 6. RVC 换源

现有：

- 全参数；
- 1–12 分钟整段/分段；
- A/B、导出、批量、重试；
- 长度锁定、爆音保护。

计划：

- 3/5/12 分钟固定回归；
- 中文歌声听感验收；
- 极长音频（>30 分钟）边界；
- 不同 index/无 index；
- 失败/取消/重启；
- 输出 sample-rate 与原始时长。

验收：

- 3 个固定样本可重复；
- 无爆音、无明显接缝；
- 输出时长误差小于 0.1 秒。

### 7. 实时 VC

现有：

- 独立服务、麦克风/loopback/混音、RVC、VB-Cable、监听、延迟档、p95。

计划：

- 30–60 分钟连续运行；
- 设备拔出/插入；
- 采样率切换；
- 高负载/显存压力；
- 外部回环测量；
- 停止/重启 20 次。

验收：

- 无崩溃、无死锁；
- 设备恢复后能重启；
- 延迟/丢帧有记录。

### 8. pymss 分离

## 八、结论

AMS Studio 已经完成主要功能，但正式发布还差“安装可信、升级可信、卸载可信、生命周期可信、质量可复现、发布可回滚”六件事。

功能开发不应继续无边界扩张；下一阶段以发布验收为主，插件拆分、完整 DAW、填词均不阻塞 v1.0。
