## 0. 一页结论

| 维度 | 结论 |
|---|---|
| 安装目录 | `%LOCALAPPDATA%\Programs\AMS\`（每用户、**不需要管理员**）：Launcher / Kernel / Services / Plugins / Runtimes / Tools / Assets / Uninstall.exe；**只放程序，不放用户资产** |
| 数据目录 | `AMS_HOME`（默认 `%LOCALAPPDATA%\AMS`，首次启动可改到空间大的盘）：config / profiles / runtime / services / models / voices / tts_voices / svs_voicebanks / datasets / projects / cache / updates / backups / logs（00 §4 + v1.1 增补） |
| 便携模式 | 发布 zip 解包即可用；`AMS_HOME = <安装目录>\Data`；卸载/删除程序目录**会删除数据**，因此便携模式卸载前必须显式确认 |
| 默认曼波 | 以 `Assets\voices\manbo.voicepack.zip` 随安装包下发（**不进 Git**）；首次启动/修复时解压到 `AMS_HOME\voices\曼波\曼波.pth + 曼波.index`，逐文件校验 sha256；实测资产 187.5 MiB |
| 后端 runtime | 共享解释器放安装目录 `Runtimes\python\<ver>\`；**每个服务独立 venv** 放 `AMS_HOME\runtime\<service>\<ver>\venv`（遵循 00 §4）；实测 pymss venv **5.81 GB**（torch 2.7.1+cu128） |
| 更新粒度 | 6 类 + 1 数据：`launcher` / `kernel` / `plugin.<id>` / `service.<id>` / `tool.<id>` / `catalog.models`；均支持独立更新与回滚；版本目录 + `current.txt` 指针实现近原子切换 |
| 防回滚/撤回 | 清单 `sequence`（单调递增）+ `withdraw`（精确版本撤回）+ `min_launcher` + `mirrors[]`；已用 7 组件示例实测 sign/verify/篡改拒绝/低 sequence 拒绝 |
| 回滚 | 应用前快照（旧包引用 + 小文件复制）；失败/健康检查不通过自动回滚；大包本地保留 90 天；txid/journal 支持断电恢复 |
| 最大风险 | ①曼波资产的权属/许可需在产品内明示（正式分发前需法务确认或用可分发音源替换）；②服务 runtime（torch/CUDA）体积与版本组合多；③M1 仍是开发路径（源码树），与安装布局存在差距（见 12 章） |

【决策】安装目录与数据目录**彻底分离**；删除/重装安装目录（非便携模式）不丢资产、不丢工程。
【决策】服务程序放安装目录 `Services\`，其 venv 依赖放 `AMS_HOME\runtime\`（00 §4），二者通过 `runtime\env.json` 映射；卸载服务只删程序目录，venv 由更新器按版本清理。
【决策】组件版本目录 + `current.txt` 指针，不使用需要管理员/开发者模式的符号链接；回滚=改指针 + 健康检查。
【待定】`Assets`（默认曼波等资产包）在更新清单中的组件类型：schema 目前只有 launcher/kernel/plugin/service/tool/catalog，建议新增 `asset` 或在 `tool.*` 下用保留 id（见 13.2）。

## 1. 设计原则

1. **程序与数据分离**：安装目录可整体删除/重装；用户资产（音源/模型/工程/数据集）只在 AMS_HOME。
2. **可回滚**：任何组件以“版本目录 + 指针”存在，回滚不改写旧目录；快照 + journal 保证失败可退。
3. **离线可用**：安装/更新/回滚不依赖网络；`.amsupd` 离线包与在线清单共用验签链。
4. **不写系统目录**：默认每用户安装，不写 `Program Files`/HKLM；提权只用于驱动/虚拟声卡等系统级组件（00 §12）。
5. **不碰用户环境**：自带 Python 运行时；不要求系统 Python/Node/CUDA；不修改 PATH（仅进程内注入）。
6. **路径短、可迁移**：默认安装路径短（避免 260 字符限制）；AMS_HOME 可换盘；工程内用相对路径。
7. **资产可溯源**：每个包/资产有 sha256 与来源记录；音源/模型权重不进 Git、不进安装包（唯一例外：默认曼波资产包）。

## 2. 安装目录布局

```text
%LOCALAPPDATA%\Programs\AMS\                    # 每用户安装（NSIS per-user），无需管理员
├─ Launcher\
│  ├─ AMS Studio.exe                              # Tauri2 外壳（WebView2）
│  ├─ resources\                                  # 前端 dist、图标、LICENSE/NOTICE
│  └─ version.json                                # 版本/构建号/签名信息
├─ Kernel\
│  ├─ 0.2.1-rc.2\                                 # 整包版本单元：Electron 壳 + dsh 运行时
│  ├─ 0.2.1-rc.3\                                 # （更新后新增，旧版本保留用于回滚）
│  └─ current.txt                                 # 当前生效版本目录名
├─ Services\
│  ├─ gateway\0.1.0\                              # 服务程序（wheel/便携包解包）
│  ├─ pymss\0.1.0\
│  └─ current\<service>.txt                       # 每服务一个指针
├─ Plugins\
│  ├─ ams.music.core\0.2.0\                       # tarball 解包后的只读载荷
│  └─ current\<pluginId>.txt
├─ Runtimes\
│  └─ python\3.12.10\                             # python-build-standalone 共享解释器（多服务复用）
├─ Tools\
│  ├─ ffmpeg\8.0.1\bin\ffmpeg.exe                 # LGPL 构建 + ffprobe
│  ├─ 7z\24.xx\
│  └─ current\<tool>.txt
├─ Assets\
│  ├─ voices\manbo.voicepack.zip                   # 默认曼波（唯一内置音源，不进 Git）
│  ├─ licenses\                                    # 第三方 NOTICE 汇总
│  └─ templates\                                   # 工程模板、诊断模板
├─ logs\                                           # 安装器/更新器日志（可关）
└─ Uninstall.exe                                   # 卸载（NSIS uninstaller）
```

| 目录 | 内容 | 写入者 | 更新粒度 | 回滚方式 | 体积估算 |
|---|---|---|---|---|---|
| `Launcher\` | 启动器 exe/资源 | 安装器/自更新 | `launcher` 全量 | 运行旧安装包 | 10–20 MB（本机 0.1.4 NSIS 1,448,763 B） |
| `Kernel\<ver>\` | Electron 壳 + dsh 运行时 | 更新器 | `kernel` 整包 | 切 `current.txt` + 重启内核 | 620–650 MB（00 §16.1 目标） |
| `Services\<svc>\<ver>\` | 服务程序 | 更新器 | `service.<id>` | 切指针 + 重启服务 | 每服务 5–60 MB（不含 venv） |
| `Plugins\<id>\<ver>\` | 插件 tarball 载荷 | 更新器/插件管理器 | `plugin.<id>` | 切指针 + 刷新页面 | 每插件 1–30 MB |
| `Runtimes\python\<ver>\` | 共享 Python 解释器 | 安装器/修复 | `tool.python`（建议） | 版本目录切换 | 80–150 MB |
| `Tools\<tool>\<ver>\` | ffmpeg/7z 等 | 更新器 | `tool.<id>` | 切指针 + 自检 | 100–150 MB |
| `Assets\` | 默认曼波、许可、模板 | 安装器 | 随安装包/资产包 | 重新解包校验 | ≈188 MB（曼波 187.5 MiB） |
| `Uninstall.exe` | 卸载器 | 安装器 | — | — | <1 MB |

**便携模式**：发布 `AMS-Studio-<ver>-portable.zip`，解包后目录内自带 `portable.flag`；启动器检测到它时把 `AMS_HOME` 设为 `<安装目录>\Data`，并在界面上提示“此模式卸载会删除数据”。便携模式不写注册表、不建开机项。

## 3. AMS_HOME 用户数据布局

```text
AMS_HOME\                                          # 默认 %LOCALAPPDATA%\AMS，可换盘/便携
├─ config\                # launcher.json、state.db（组件/更新历史/依赖）、诊断配置
├─ profiles\music\        # DSH profile：package.json、cordis.patch.yml、node_modules（插件激活区）
├─ kernel\dsh\            # DSH_HOME（凭据、storages、session 数据；启动器注入 DSH_HOME）
├─ runtime\               # 各服务 Python 运行时（00 §4）
│  ├─ gateway\0.1.0\venv\
│  ├─ pymss\0.1.0\venv\
│  ├─ rvc-train\<ver>\venv\ · rvc-infer\<ver>\venv\
│  ├─ gptsovits\<ver>\venv\ · tts-qwen\<ver>\venv\
│  ├─ mixer\<ver>\venv\ · evaluator\<ver>\venv\
│  ├─ ports.json          # 网关/服务端口（127.0.0.1，动态分配）
│  ├─ gateway.token       # 32+ 字节随机 token（不写日志）
│  ├─ kernel.log/kernel.json  # 内核日志与 pid/url（M1 已实现）
│  └─ env.json            # service → {python, venv, version} 映射
├─ services\             # 各服务配置/密钥/工作目录（程序在安装目录）
├─ models\               # 基础模型缓存：rvc/、pymss/、asr/、vocoders/、catalog.json
├─ voices\               # 音源库（严格 voices/<名称>/<名称>.pth(+index)）
├─ tts_voices\ · svs_voicebanks\   # TTS/SVS 声库（不属于 RVC 音源库）
├─ datasets\             # 数据集不可变快照（v1.1 新增）
├─ projects\             # 作品工程（00 §7；含 eval/、mix/、exports/）
├─ cache\                # downloads/（包缓存）、manifests/、thumbs/、tmp/
├─ updates\              # staging/、snapshots/<txid>/、journal/、.lock
├─ artifacts\            # Gateway 任务产物（M1 已实现）
├─ backups\              # projects/（工程备份）、trash/（回收站：音源 7 天/工程 30 天）
└─ logs\                 # launcher/、kernel/、gateway/、services/（按天滚动）
```

| 目录 | 归属 | 说明 |
|---|---|---|
| `config\state.db` | 启动器 | 组件状态、更新历史、依赖缓存、最近清单 sequence（防回滚） |
| `profiles\music\` | 内核/插件管理器 | 插件激活区；插件载荷在安装目录，激活=写入/链接到 profile node_modules |
| `kernel\dsh\` | 内核 | DSH_HOME（含凭据；启动器不读 key） |
| `runtime\` | 启动器/服务 | 每服务 venv + 端口/token/日志；**可整体删除后重建**（不丢资产，只重装依赖） |
| `models\` | 模型库 | 由 catalog.models 下载；校验 sha256；可清理重下 |
| `updates\` | 更新器 | 暂存/快照/journal；失败回滚依赖它，勿手工删 |
| `artifacts\` | Gateway | 任务产物（与工程产物区分：工程产物在 projects/） |

【偏差/建议 00 v1.3 增补】00 §4 未列 `kernel\dsh\`、`services\`、`artifacts\`、`backups\trash\` 四项，但 M1 实现与插件分册已依赖；建议补入 00 §4。
【决策】`profiles\music\` 由内核与 DSH 插件管理器维护，启动器只在更新/回滚时写入 patch 快照副本，避免两边同时改。

### 4.2 安装流程

| 步骤 | 动作 | 校验/失败处理 |
|---|---|---|
| 1 | 首次启动向导“推荐安装”默认勾选“内置音源曼波（≈188 MB）”；安装器可选“随装” | 磁盘预检 ≥ 400 MB（解压+临时副本） |
| 2 | 从 `Assets\voices\manbo.voicepack.zip` 解压到临时目录 | zip 完整性 + 包内 manifest 版本 |
| 3 | 逐文件 sha256 校验（对照包内 manifest） | 不符→删除临时目录，报 `ASSET_E_HASH` |
| 4 | 复制为 `voices\曼波\曼波.pth/.index` | 已存在则默认“跳过（保留用户文件）”，可选手动覆盖；不允许静默覆盖 |
| 5 | 调 Gateway `POST /voices/scan`（或启动后自动扫描） | 状态 ok、sr/info/f0 解析成功、index 维度 768 |
| 6 | 写入 `config\state.db` 的 asset 记录（asset_id=manbo、version、sha256、installed_at） | 失败→标记缺失，界面给“修复默认音源” |
| 7 | 插件默认音色选择器默认选中“曼波” | 缺失时提示修复，不阻断其他功能 |

**修复入口**：设置/组件管理 → “默认音源” → 修复 = 重新解包+校验+覆盖（用户文件已被修改时先备份到 `backups\trash\voices\`）。

【风险】曼波为第三方音色资产（用户指定“经典且本机已有”）；**正式对外分发前需确认来源与许可**，产品关于页须标注资产来源与“仅供个人使用”提示；若无法确认，改为“首次启动在线/离线导入”而不随包。
【待定】资产包版本化与更新通道：建议新增组件类型 `asset`（见 13.2）；首版可跟随 `launcher` 更新（低频）。

## 5. 后端 runtime 目录与版本

### 5.1 目录规则

- **共享解释器**：安装目录 `Runtimes\python\3.12.10\`（python-build-standalone，PSF-2.0），只读、可被多服务复用。
- **每服务 venv**：`AMS_HOME\runtime\<service>\<version>\venv\`（pyvenv.cfg 指向共享解释器）；venv 内只装该服务依赖；**不要装到共享解释器**。
- **映射**：`runtime\env.json` 记录 `service → {version, python, venv, installed_at, torch, cuda}`；启动器/网关只按映射拉起，不猜路径。
- **升级**：新版本 venv 新建（不就地升级），成功后切 `runtime\<service>\current.txt`；旧 venv 保留至下一版本验收后清理（回滚用）。
- **修复**：删除该服务 venv → 重装（幂等）；共享解释器损坏时所有服务重建。
- **环境变量**：启动器为子进程显式注入 `AMS_HOME`/`AMS_RVC_PYTHON`（兼容 M1 开发路径）/`PYTHONNOUSERSITE=1`；不修改系统 PATH。

### 5.2 服务 runtime 清单（M1 实测/估算）

| 服务 | 运行时基线 | 依赖特征 | 磁盘估算 | M1 现状 |
|---|---|---|---|---|
| `gateway` | Python 3.12 | fastapi/uvicorn/sqlite | 0.15–0.25 GB | ✅ 源码 0.1.0 跑通（源码树 .venv） |
| `pymss` | Python 3.12 | torch 2.7.1+cu128 | **5.81 GB（实测）** | ✅ GPU 冒烟通过（SCNet RTF 0.06；BSR chunk 240k 峰值 2.6 GB） |
| `rvc-train` / `rvc-infer` | Python 3.12（待锁定） | torch + RVC 2.3.260718 | 3.5–5.5 GB | ⚠️ 旧 RVC 3.9.13+torch2.0cu118 仅验证；新运行时 M2 建 |
| `gptsovits` | Python 3.12 | torch + GPT-SoVITS v2Pro | 4–6 GB | ⚠️ 旧包 3.9.25+torch2.6cpu 仅验证 |
| `tts-qwen` | Python 3.12 | torch，权重走 models/ | 3–5 GB + 模型 | — |
| `dataset` | Python 3.12 | faster-whisper base + 对齐工具 | 1–2 GB | — |
| `mixer` | Python 3.12 | numpy/scipy/pyloudnorm + ffmpeg | 0.3–0.6 GB | — |
| `evaluator` | Python 3.12 | torch + 指标模型 | 3–5 GB | — |
| `vc`（P1） | 独立音频服务 | RVC 实时 + WASAPI | 2–4 GB | — |
| `msvc-convert` | Rust（启动器内置）/ Python 兜底 | 无需 torch | 启动器内 | ✅ 工具 v0.4.0（本机 3/3 PASS） |
| 模型缓存 `models\` | — | pymss catalog / HuBERT / RMVPE / ASR | 5–20 GB（按需） | pymss 已下载部分模型 |

【决策】服务 venv 严格“一服务一版本一目录”；**不做跨服务共享 site-packages**，避免 torch/CUDA 冲突（可行 §2.2 原则 4）。
【待定】RVC 新运行时的 torch/CUDA 组合（40 系可用 cu118/cu128；需 M2 实测后锁定），以及是否统一到 3.12。
【风险】runtime 总量可能达 25–30 GB；安装向导需明确“最小 30 GB / 推荐 80 GB”（启动器 §4.2），并在组件管理页显示占用。

## 6. 组件更新粒度与回滚

### 6.1 粒度总表

| 组件 | 更新单位 | 落盘位置 | 需重启？ | 快照内容 | 健康检查 |
|---|---|---|---|---|---|
| `launcher` | 全量安装包（NSIS/MSI） | `Launcher\` | 是（自更新后重启） | 旧安装包路径 + version（不复制大包） | 启动成功 + 版本号 + 托盘 |
| `kernel` | 全量整包 | `Kernel\<ver>\` | 是（重启内核） | 旧版本目录指针 + profile patch + versions.json | 内核 200 + 插件 API 握手 + 页面可开 |
| `plugin.<id>` | npm tarball | `Plugins\<id>\<ver>\` + profile 激活 | 否（页面刷新） | 旧 tarball + profile 相关 patch | 插件加载无错 + 页面注册成功 |
| `service.<id>` | wheel/便携 zip | `Services\<id>\<ver>\` + `runtime\<id>\<ver>\venv` | 服务重启 | 旧程序目录 + venv 指针 + 配置 | `/health` + 端口 + 版本 |
| `tool.<id>` | zip/exe | `Tools\<id>\<ver>\` | 工具级自检 | 旧目录 | 执行 `-version` 等自检 |
| `catalog.models` | 清单 JSON（+模型文件独立下载） | `models\catalog.json` | 否 | 旧清单 | JSON 校验 + 抽样 sha256 |
| 默认曼波资产 | 资产包（随安装包/离线包） | `Assets\voices\manbo.voicepack.zip` → `voices\曼波\` | 否 | 旧资产包 | 文件 sha256 + voices 扫描 |

### 6.2 版本指针与原子切换

- 每个可多版本组件目录内有 `current.txt`（或 `current\<id>.txt`）：内容为版本目录名，**切换=原子写入该小文件**。
- 应用流程：解压到 `<id>\<new-ver>\` → 静态检查 → 健康检查（以新目录临时启动/探测）→ 写 `current.txt` → 正式重启。
- 失败：不写指针（或写回旧值）→ 旧版本继续生效；无需复制大目录。
- 不使用符号链接/junction，避免 Windows 权限与杀软误报；目录改名同卷原子。

### 6.3 快照 / journal / 回滚

- 快照目录：`AMS_HOME\updates\snapshots\<txid>\`；记录每个组件的旧版本目录、配置文件、profile patch 副本；大包只记引用（`cache\downloads\` 保留 90 天）。
- journal：`updates\journal\<txid>.jsonl`（fsync 逐行写）；崩溃后启动器按 journal 判定“继续/回滚/标记失败”。
- 回滚粒度：**组件级**（单个组件退回上一版本）与**批次级**（整个 txid 撤销）。回滚前再次健康检查。
- 保留期：旧包/旧版本目录保留 90 天（可配置）；磁盘不足时先清理超期旧版本。
- 与任务互斥：应用 kernel/gateway/service 更新前必须确认 Gateway 无 running/queued 任务与实时会话；否则排队或取消（启动器 §6.12）。

### 6.4 防回滚 / 撤回 / 离线

- `sequence` 单调递增，本地记录已见最大值，低于它拒绝安装（dev 通道显式允许降级需二次确认）。
- `withdraw`：清单列出撤回版本（如 `plugin.ams.music.core@0.1.3`）；命中后不再提示，已装版本提示回退。
- `min_launcher`：老启动器必须先自更新才能处理清单。
- `mirrors[]`：组件级镜像数组，按顺序重试，**每个镜像必须返回相同 sha256**。
- 离线包 `.amsupd`（启动器 §6.14）：zip 内含 `manifest.json + manifest.sig + packages\ + README.txt`；导入时验签→校验包 sha256→与在线相同的快照/应用/回滚流程。

## 8. 组件状态与完整性

| 数据 | 位置 | 说明 |
|---|---|---|
| 组件状态 | `AMS_HOME\config\state.db`（component_state） | id/kind/version/channel/install_path/installed_at/source/hash/rollback_available |
| 更新历史 | state.db（update_history） | txid、批次、结果（success/failed/rolled_back）、时间 |
| 依赖缓存 | state.db（component_dependencies） | 离线依赖求解用 |
| 已见 sequence | state.db（meta） | 防回滚；清空=重置安全状态（需确认） |
| 安装清单 | 安装目录 `version.json` + 各组件的 `files.sha256` | 完整性校验/修复 |
| 指针 | 各组件 `current*.txt` | 真实生效版本；与 state.db 不一致时以文件为准并自愈 |

- 完整性校验：按组件包内文件清单逐个 sha256（大目录抽样 + 关键文件全量）；失败标 `corrupted`，提供“修复（重装该组件）”。
- 未登记文件：组件目录出现清单外文件 → 警告（可能是用户误放），不自动删。
- 孤儿清理：安装目录中无指针指向且超 90 天的版本目录 → 提示可清理；`updates\staging` 残留 → 启动时清理。

## 9. 安装 / 升级 / 卸载流程

| 场景 | 流程 | 要点 |
|---|---|---|
| 在线安装 | NSIS per-user：`/S /D=<dir>` 静默可用；默认 `%LOCALAPPDATA%\Programs\AMS` | 无管理员；写 HKCU 卸载项与快捷方式；预检 WebView2/磁盘 |
| 便携安装 | 解压 zip → 运行 `Launcher\AMS Studio.exe` | 检测 `portable.flag` → AMS_HOME=.\Data；不写注册表 |
| 首次启动 | 创建 AMS_HOME 与子目录 → 写入 config/state.db → 向导（许可/目录/环境/组件/曼波/拉起网关+内核） | 任一步可退出后续继续；失败给诊断入口 |
| 升级 | 启动器更新中心检查 → 下载/验签 → 快照 → 应用 → 健康检查 → 成功/回滚 | 与任务互斥；内核/服务需重启 |
| 修复 | 组件管理 → 校验/修复（重装组件，保留数据） | 修复不重置配置与资产 |
| 卸载 | 停止内核/网关/服务 → 运行 Uninstall.exe → 删程序目录 → **默认保留 AMS_HOME** | 勾选“同时删除用户数据”需二次确认；便携模式需额外确认 |
| 重装 | 安装包覆盖安装或卸载后重装 | 复用 AMS_HOME；state.db 自动重建索引 |

- 卸载不删除：`voices\ models\ projects\ datasets\ backups\`（除非用户显式勾选）。
- 卸载删除：程序目录、HKCU 运行项/快捷方式、`cache\downloads` 中可再下载的包（可选）。
- 安装日志：`<安装目录>\logs\install-*.log` 与 `AMS_HOME\logs\launcher\`；失败诊断包可一键导出。
