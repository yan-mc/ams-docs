### 2.4 克隆过程记录（含两次失败，便于复现/排障）

1. **第一次后台克隆**：命令中同时写了 Start-Transcript 日志到任务目录之外（违反只写任务目录约束），为避免越界写文件我终止了该后台任务；但 git 子进程未随之退出，残留 .git/objects 与 2 个 git 进程。
2. **第二次克隆**：旧 git 进程仍占用目标目录（.git/index.lock、tmp_pack），Remove-Item 失败，clone 报 "destination path already exists and is not an empty directory"（exit 128）。
3. **处理**：Stop-Process 清理残留 git 进程 -> 递归删除残留目录 -> 改用 tag 浅克隆 -> 成功（exit 0）。
4. 经验：克隆/大目录操作前先确认无残留 git 进程；日志只写任务目录；tag 浅克隆比 blob-less 单分支克隆更稳（对单 commit 工作树而言）。
