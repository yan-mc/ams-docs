## 0. 摘要与决策速览

**一句话定位**：音源质量 70% 取决于数据。数据集工作室把「导入 → 切片 → ASR 转写与文本比对 → 强制对齐 → 质量指标 → 清洗 → 导出（RVC / TTS / SVS）」做成一条**本地、可质检、可复现**的数据流水线，为音源炼制（RVC）、TTS 微调（GPT-SoVITS）、SVS 声库（DiffSinger/MakeDiffSinger）提供标准数据集，并给 Agent 一组 `music_dataset_*` 工具做自动质检与清洗。

**技术基座（2026-10-19 版本）**：
- ASR：**faster-whisper 1.2.1（MIT）**（默认，本地 CUDA/CPU）；中文/国内可选 **FunASR 1.4.16（MIT）**；词级时间戳可选 **WhisperX（BSD-2-Clause）**。【事实：调研 §6.4；版本/许可见 §5.3】
- 强制对齐：语音用 WhisperX/MFA；**歌声优先 TIFA v1.0.0（MIT，OpenVPI）**；备选 SOFA（OpenVPI，许可【待核实】）与 MFA（MIT）。【事实：SVS 报告 §6.2】
- 切片/VAD：**openvpi/audio-slicer（MIT）** 的静音检测算法 + **silero-vad 6.x（MIT）** + 自研策略（固定长度/按句）。
- 质量指标：基础信号指标自研（无模型）；模型指标可选 **DNSMOS P.835 / UTMOS22（MIT）/ NISQA（代码 MIT、权重 CC-BY-4.0）/ 说话人相似度（speechbrain/WeSpeaker，Apache-2.0）**。
- 清洗：复用插件 02 人声分离（pymss 2.1.9，MIT）做去伴奏/去混响/降噪，**不自研分离**；F0 用 **pyworld 0.3.6（MIT）**/**librosa**；响度用 **pyloudnorm 0.2.0（MIT）**。
- 明确排除：**parselmouth（GPL-3.0）**、pedalboard/matchering（GPL-3.0）等 GPL 组件；**任何音频默认不上传**。

| 决策 ID | 决策 | 理由/依据 |
|---|---|---|
| D1 | 独立服务 **`ams-svc-dataset`**（Python 3.12，CPU 优先、GPU 可选），Gateway 拉起并监管 | 00 §3；ASR/对齐/指标都是重依赖，独立环境 |
| D2 | 数据集是 AMS_HOME 的一级资产：`AMS_HOME\datasets\<id>\`，可跨工程复用；**与 00 §4 未列该目录冲突**，已标【偏差】待回写 | 数据集比工程生命周期长；避免复制 |
| D3 | 数据集**不可变快照**：`dataset_id + version + manifest hash`；任何修改产生新版本，导出记录版本号 | 可复现/可回滚；训练可追溯 |
| D4 | 切片引擎 = 静音切片 + VAD + 固定长度 + 按句 四种模式；**按目标后端预设参数**（RVC 3–15 s / TTS 3–10 s / SVS 按句 2–10 s） | 三类训练数据要求不同（可行性 §6.1） |
| D5 | ASR 默认 **faster-whisper**，可选 **FunASR**；不做云端 ASR（P2 亦可默认关） | 本地优先/隐私；中文场景 FunASR 备选 |
| D6 | 强制对齐：语音用 **WhisperX**（快、词级）或 **MFA**（音素级、批量稳）；歌声用 **TIFA**（专为歌声/带伴奏设计） | SVS 报告 §6.2；MFA 歌聲需专门模型 |
| D7 | 质检分三层：**Tier0 基础信号（必做，无模型）** / **Tier1 模型指标（可选下载）** / **Tier2 人工抽听清单**；阈值按目标后端给三套预设 | 避免一上来强制下载大模型；渐进增强 |
| D8 | 清洗复用插件 02：去伴奏/去混响/降噪通过 `separate.pymss` 任务完成，数据集服务只编排与验收 | 不重复造轮子；GPU 锁统一 |
| D9 | 导出四类：**RVC 数据集 / GPT-SoVITS 数据集 / SVS 标注包 / 通用 dataset.json**；不直接跑训练 | 与插件 01/05 及填词成歌插件解耦 |
| D10 | 全程本地处理，**默认不上传任何音频/文本**；联网仅用于模型下载/更新 | 00 §12 本地优先；隐私 |
| D11 | 不做「自动修音/自动写歌词/自动混音」；SVS 的歌词-音符编辑属于填词插件 | 边界清晰 |
| D12 | 排除 GPL 组件（parselmouth 等）；DeepFilterNet 等许可未核实的组件只作可选实验 | 许可干净；避免 AGPL/GPL 污染 |

**Top 风险**：① 质量阈值与真实听感不一致（指标好≠好听）→ 必须保留人工抽听与 A-B（§9/§13）；② ASR 模型/对齐工具链重、下载大、Windows 兼容性问题（§9.3）；③ 数据集目录/版本模型与 00 的【偏差】需 Lead 确认（§1.3）。

## 1. 目标与非目标

### 1.1 目标（可验收）

| ID | 目标 | 量化/验收 |
|---|---|---|
| G1 | 用户 10 分钟内把「录音文件/视频/文件夹」变成可用训练数据集 | 导入→切片→ASR→质检→导出全流程 ≤ 10 分钟（10 分钟音频） |
| G2 | 三类数据集（RVC/TTS/SVS）都能一键导出且格式被下游直接接受 | 插件 01/05 与填词成歌插件各跑通一次端到端训练 |
| G3 | 质量指标可解释、可执行 | 每片段有指标 + 不合格项 + 建议动作 |
| G4 | 清洗可批量且可验收 | 去伴奏/去混响/降噪后指标提升可量化（SNR/DNSMOS 前后对比） |
| G5 | 数据集可复现/可回溯 | 版本记录工具版本、参数、模型版本、hash |
| G6 | Agent 可完整操作 | ≥14 个 `music_dataset_*` 工具（§8） |
| G7 | 隐私安全 | 默认零上传；音频仅在本机；模型下载可审计 |
| G8 | 性能可接受 | 10 分钟音频质检 ≤ 2 分钟（GPU）；ASR RTF ≤ 0.5（GPU） |

### 1.2 非目标

| 非目标 | 说明 |
|---|---|
| 不做训练（RVC/GPT-SoVITS/DiffSinger） | 训练在插件 01 与各下游插件 |
| 不做音频编辑/修音/混音 | 只做「切/选/清洗/质检」；精修交给 DAW/混音插件 |
| 不做歌词创作/音符编辑 | SVS 标注编辑属填词成歌插件（`ams.music.singing`，分册另行）；本插件只产出对齐初稿 |
| 不做云端 ASR/云端质检 | 默认关闭；P2 也不作为卖点 |
| 不做数据抓取/爬取/下载 | 用户自备素材（00 §1） |
| 不做模型训练数据授权审查的法律判断 | 提供记录与提示，最终由用户负责 |

## 2. 用户与场景

### 2.1 用户角色

| 角色 | 典型诉求 | 关键差异 |
|---|---|---|
| 翻唱/换声爱好者 | 把 20 分钟录音变成 RVC 训练集，先自动清洗+切片 | 关注「够不够 10 分钟」与底噪/混响 |
| TTS/配音用户 | 1–5 分钟干声 + 准确文本 → GPT-SoVITS 微调 | 关注转写准确率与参考音频 |
| SVS/填词用户 | 1–3 小时演唱 + 歌词 + MIDI → DiffSinger 标注 | 关注对齐与音素/音高标注 |
| 主播/播客 | 长录音切片、去口头禅/静音、响度统一 | 关注批量与清洗 |
| AI 协作用户 | 「帮我把这批录音做成 RVC 数据集，不合格的列出来」 | 关注自动化与可解释报告 |
| 开发者/排障 | 看指标、对齐、日志 | 关注可复现与工具版本 |

### 2.2 场景表

| 场景 | 输入 | 输出 | 关键功能 | 验收点 |
|---|---|---|---|---|
| S1 RVC 数据集 | 录音/视频/分离后干声 | wav 切片 + manifest | 切片、去混响/降噪、SNR/削波质检、导出 | 总时长 ≥10 min；SNR ≥20 dB；无爆音 |
| S2 GPT-SoVITS 数据集 | 1–5 分钟干声 + 文本 | wav + `.list` + 参考音频 | ASR 转写、文本比对、切片、导出 | CER <5%；参考音频 3–10 s |
| S3 SVS 标注 | 演唱录音 + 歌词（+MIDI） | wav+TextGrid+拼音/音素+音高 | 强制对齐（TIFA/MFA）、音素/音高统计、导出 | 对齐失败率 <2%；歌词覆盖率 100% |
| S4 长录音整理 | 1 小时播客/直播录音 | 切片 + 静音剔除 + 响度统一 | VAD/静音切片、批量、去口头禅（P2） | 切片边界自然；无半句 |
| S5 数据清洗 | 已切片但不干净的素材 | 清洗后片段 + 前后指标 | 去伴奏（pymss）、去混响、降噪、剔除 | 指标提升可量化；人工抽听通过 |
| S6 质检报告 | 任意数据集 | 质量报告（JSON/CSV/图表） | Tier0/1 指标、不合格清单、修复建议 | 报告可导出；每条不合格有建议 |
| S7 AI 批处理 | 自然语言 | 同上 | Agent 调工具完成全流程并汇报 | 工具可审计/可取消/可回滚 |
| S8 数据集复用 | 已有数据集 | 新版本导出给不同后端 | 版本管理、多目标导出 | 同版本导出可复现 |

### 2.3 AI 操作场景（Agent 能做/不能做）

| 能做 | 不能做（必须人确认） |
|---|---|
| 导入/检测音频、建议切片参数、执行切片 | 删除用户原始素材/覆盖已有数据集版本 |
| 跑 ASR、比对文本、标出差异、建议修改 | 自动改写用户文本并用于训练（必须先确认） |
| 跑对齐、统计音素/音高、生成质检报告 | 上传音频/文本到云端 |
| 发起清洗（去伴奏/去混响/降噪）并对比前后指标 | 下载超过阈值（默认 2GB）的 ASR/质检模型 |
| 导出三类数据集并校验格式 | 修改已有数据集版本（只能新建版本） |
| 推荐下一步（补录/重切/清洗/补文本） | 替用户做声音授权/版权判断 |

【决策】Agent 创建的每个数据集操作都记录：`agent_session_id`、意图摘要、工具版本、参数快照；数据集详情可查看「谁在什么时候做了什么」。

| F-40 | 一键「按目标后端优化」：RVC 重切+清洗；TTS 补文本；SVS 对齐 | P1 | 每类有向导；执行前预估耗时 |

### 3.2 导入与素材检查（P0）

- 支持容器：wav/flac/mp3/m4a/aac/opus/ogg/wma（经 ffmpeg）、视频 mp4/mkv/mov/webm（抽音轨）；拒绝 DRM/加密文件。
- 探测信息：时长、采样率、声道、位深/码率、编码、峰值/LUFS、削波比例、静音比、DC offset、噪声底（前 1 s 静音段估计）。
- 导入模式：【决策】默认「引用」（记录路径 + sha256，不复制大文件）；用户可切「复制到 datasets/<id>/source/」。工程删除不影响数据集引用，但路径失效需重链。
- 去重：同一 sha256 只保留一条；感知哈希（P1）用于近重复检测。
- 自动分轨：视频抽音轨到临时 wav（16-bit/32-bit float，保持采样率），源文件不变。

### 3.3 切片策略（P0）

| 模式 | 算法 | 默认参数 | 适用 |
|---|---|---|---|
| 静音切片 | openvpi/audio-slicer 的 RMS/过零检测（MIT，算法简单可自实现） | 阈值 -40 dB，最小片段 5 s，最大 15 s，最小静音 300 ms，边界 padding 200 ms | RVC/TTS 通用 |
| VAD 切片 | silero-vad（MIT）语音段检测 + 边界平滑 | 阈值 0.5，最小语音 250 ms，最大片段 10 s | 噪声/视频/访谈 |
| 固定长度 | 按时长均分（可加 crossfade 重叠） | 10 s（TTS）/15 s（RVC） | 音乐/持续人声 |
| 按句 | 用户文本按标点分句 → 强制对齐 → 按句边界切 | 句长 2–10 s | TTS/SVS 对齐友好 |

- 【决策】片段命名：`seg-0001.wav`（数据集内唯一）；保留原始时间偏移（`source_start/source_end`）便于回溯。
- 【决策】切片产物存 `segments/`（默认 44.1k/32-bit float 保留信息），导出时按目标后端重采样（RVC 40k/48k、GPT-SoVITS 32k、SVS 44.1k）。
- 边界质量：切片边界落在静音/过零附近；提供「边界微调」±500 ms 与「重切」。
- 【待定】是否支持「按说话人切换切片」（多人录音）；建议 P1 与说话人管理一起做。

### 3.4 ASR 转写与文本比对（P0）

| 项 | 方案 |
|---|---|
| 默认引擎 | faster-whisper 1.2.1（CTranslate2；模型 small/medium/large-v3，按显存选择；默认 medium 或 large-v3-turbo【待定】） |
| 备选引擎 | FunASR 1.4.16（Paraformer 中文；时间戳；国内网络友好） |
| 词级时间戳 | WhisperX（BSD-2）对齐增强（P1） |
| 语言 | 自动检测 + 用户指定（zh/en/ja/ko/yue 等） |
| 文本比对 | 归一化（标点/大小写/全半角/数字读法）后算 CER（字级）/WER（词级）；差异高亮；按片段标 `verified/review/rejected` |
| 参考文本来源 | 用户粘贴/导入 txt/csv/srt；或「按句切片」时来自分句文本 |
| 置信度 | ASR 平均 logprob + 对齐置信度；低置信片段优先人工复核 |
| 导出 | JSONL（片段/文本/时间戳/置信度/CER）、SRT、纯文本 |

- 【决策】文本比对口径：中文按字符 CER（含拼音级可选）、英文按词 WER；**去标点/统一全半角/数字转中文读法**后再比，避免误判。
- 【推断】阈值：CER < 5% 合格；5–15% 需复核；>15% 建议重录或改文本。可在阈值预设中调整。
- 【风险】歌声 ASR 准确率低于语音（颤音/拖长/背景伴奏），歌声转写建议先分离人声再 ASR（调用插件 02）。

### 3.5 强制对齐（P0/P1）

| 引擎 | 层级 | 适用 | 输入 | 输出 | 许可 |
|---|---|---|---|---|---|
| **TIFA v1.0.0** | 音素级 | **歌声**（带伴奏/噪声也可） | 人声 + 文本（+语言） | TextGrid/JSON（词/音素时间） | MIT（OpenVPI） |
| WhisperX | 词级 | 语音 | 音频 + ASR 文本 | 词级时间戳 JSON | BSD-2-Clause |
| MFA | 音素级 | 语音（需词典/声学模型；歌声需专门模型） | 音频 + 文本 + 词典 | TextGrid | MIT |
| SOFA（备选） | 音素级 | 歌声 | 音频 + 文本 | TextGrid | 【待核实】 |

- 【决策 D6】默认路由：检测「是否歌声」→ 是：TIFA；否：WhisperX（P0）或 MFA（音素级需求，P1）。
- 对齐失败处理：片段标记 `align_failed`，给出原因（文本不匹配/静音/串音）；不阻塞整集，导出时排除或标注。
- SVS 用途：对齐结果 → 生成歌词-音素时间轴初稿，供填词成歌插件的编辑器/MakeDiffSinger 标注使用；**本插件不生成 .ds**（属填词成歌插件）。
- 音高：pyworld 提取 F0（每 10 ms），统计 F0 范围、颤音、跑调（与对齐音符比较暂不做，P1 与填词成歌插件协作）。

### 3.6 质量指标（Tier0/1/2 + 阈值预设）

**Tier0 基础信号指标（必做，纯 CPU，无模型）**

| 指标 | 计算 | RVC 默认阈值 | TTS 默认阈值 | SVS 默认阈值 | 不合格处理建议 |
|---|---|---|---|---|---|
| 采样率 | 探测 | ≥40 kHz | ≥32 kHz | ≥44.1 kHz | 重采样/重录 |
| 位深/编码 | 探测 | ≥16-bit；推荐无损 | 同左 | 同左 | 转 wav |
| 时长 | 片段 | 3–15 s | 3–10 s | 2–10 s（按句） | 重切 |
| 峰值 | 采样点最大绝对值 | ≤ -1 dBFS | ≤ -1 dBFS | ≤ -1 dBFS | 归一/限幅 |
| 削波比例 | 连续满幅样本占比 | < 0.01% | < 0.01% | < 0.01% | 剔除/重录 |
| LUFS | pyloudnorm（整合响度） | -23…-16（建议统一） | -23…-16 | -23…-16 | 响度归一 |
| 静音比 | 片段内 < -50 dBFS 比例 | < 20% | < 20% | < 15% | 重切/裁剪 |
| DC offset | 均值绝对值 | < 0.001 | < 0.001 | < 0.001 | 高通滤波 |
| 噪声底 | 片段内最静 200 ms 的 RMS | ≤ -55 dBFS（推断） | ≤ -55 dBFS | ≤ -50 dBFS | 降噪/重录 |
| 估算 SNR | 语音段 RMS - 噪声底 RMS | ≥ 20 dB | ≥ 25 dB | ≥ 20 dB | 降噪/重录 |
| RT60 估算（可选） | 简易衰减拟合 | ≤ 0.35 s（推断） | ≤ 0.3 s | ≤ 0.4 s | 去混响 |
| 语速/字密度（TTS） | 字数/时长 | — | 2–6 字/秒（zh） | — | 复核 |

**Tier1 模型指标（P1，按需下载模型；可逐项启用）**

| 指标 | 模型/工具 | 许可 | 用途 | 默认阈值【推断】 |
|---|---|---|---|---|
| DNSMOS P.835（OVRL/SIG/BAK） | Microsoft DNS-Challenge / ONNX 转换包 | 代码 MIT；权重 CC-BY-4.0（第三方包声明，【待核实】） | 语音质量/背景侵入 | OVRL ≥ 3.0 |
| UTMOS22 | sarulab-speech/UTMOS22 | MIT | 自然度 MOS 预测 | ≥ 3.0 |
| NISQA | gabrielmittag/NISQA | 代码 MIT；权重 CC-BY-4.0 | 质量/噪声/混响 | MOS ≥ 3.0 |
| 说话人相似度 | ECAPA-TDNN（speechbrain Apache-2.0 / WeSpeaker Apache-2.0） | 相似度 cos ≥ 0.75（同人） | 说话人一致性 | 一致性合格率 ≥ 95% |
| ASR CER | faster-whisper/FunASR | MIT | 文本准确性 | RVC 不需要；TTS < 5% |

**Tier2 人工抽听（P1）**：按 5–10% 随机 + 100% 不合格候选 + 低置信度片段生成抽听清单；页面支持「合格/重切/剔除/重录」标记，结果回写片段状态。

**阈值预设**【决策 F-19】：`dataset.profiles = {rvc-strict, rvc-default, tts-default, svs-default, custom}`；导出时按目标后端检查必需项（例如 RVC 必须有足够总时长与干净人声；TTS 必须有文本；SVS 必须对齐成功）。

### 3.7 清洗（P0，复用分离插件）

| 操作 | 实现 | 输入 | 输出 | 验收 |
|---|---|---|---|---|
| 去伴奏/人声提取 | 调用 `separate.pymss`（推荐 `bs_roformer_voc_hyperacev2` 或 `5_HP-UVR`） | 混合音频/片段 | vocals 片段 | 伴奏残留可听下降；无音乐性伪影 |
| 去混响/去回声 | `separate.pymss`（dereverb/deecho 模型） | 人声片段 | dry 片段 | RT60 估算下降/听感更干 |
| 降噪 | 优先 pymss 去噪模型（UVR-DeNoise-Lite / Mel-Band denoise）；DeepFilterNet 仅实验 | 片段 | 降噪片段 | 噪声底下降；无「水声」 |
| 响度归一 | pyloudnorm + 限幅 | 片段 | 归一后片段 | LUFS 目标一致；峰值 ≤ -1 dBFS |
| 裁剪首尾静音 | 自研（能量阈值） | 片段 | 裁剪后 | 不切掉字头/尾音 |
| 剔除不合格 | 按指标/人工标记 | 数据集 | 新版本 | 源数据不变；版本可回滚 |
| 削波修复 | 限幅/软削波（简单）或标记重录 | 片段 | 修复/标记 | 不引入明显失真 |

- 【决策 D8】清洗任务内部编排：`dataset.clean` → 创建 `separate.pymss` 子任务（同一 GPU 锁队列）→ 完成后回填指标 → 片段状态 `cleaned`。
- 清洗前后对比：保存指标 diff（SNR/DNSMOS/峰值/噪声底），页面显示「清洗收益」。
- 【待定】是否自动推荐清洗链（如「先分离人声再去混响」）：建议 P1 做规则推荐，不做自动执行。

### 3.8 标签、元数据与版本（P0）

- 数据集级：名称/说明/类型（rvc/tts/svs/generic）/目标后端/语言/说话人列表/创建时间/来源/许可备注/总时长/片段数。
- 片段级：说话人/语言/文本/音素/音高统计/时间偏移/指标/状态（raw/sliced/aligned/validated/cleaned/exported/rejected）/标签。
- 【决策 D3】版本：每次「切片/清洗/剔除/导出」生成新 `version`（`v001`, `v002`…），保存 `manifest.json` + `manifest.sha256`；旧版本可查看/导出/删除（需确认）。
- 中文标签：支持自由标签 + 预设标签（情绪/场景/设备/底噪类型）。

### 3.9 导出格式（P0/P1）

**RVC 数据集**（`exports/rvc/<dataset>_<version>/`）：

- 【决策】数据集工作室**只导出 wav + manifest**，不改写 RVC 的 preprocess 产物（`0_gt_wavs/1_16k_wavs/2a_f0/2b-f0nsf/3_feature256|768`）；由插件 01 调用 RVC 官方 preprocess 完成。避免与上游流程重复/漂移。
- 【决策】与插件 01 的消费模式：**默认「就绪快照引用」**（trainer 直接读取 `dataset_id@version` + segments + 质检报告 + 授权声明，不复制音频，只记录 `dataset_ref` 与 manifest hash）；`exports/rvc/` 目录用于离线迁移、其他工具或用户手动训练。

- 采样率建议：48k（RVC 48k 模型）或 40k；由插件 01 训练配置选择时二次确认。

**GPT-SoVITS 数据集**（`exports/gptsovits/<dataset>_<version>/`）：


| TTS 数据集 | 导入 → 切片（3–10s）→ ASR → 与文本比对 → 修正差异 → 生成参考音频 → 导出 | 文本缺失：暂停并提示导入/粘贴文本 |
| SVS 标注 | 导入演唱 → 按句切 → 歌词导入 → TIFA 对齐 → 音高统计 → 导出 | 对齐失败：标红片段，提示改文本/重切 |
| 清洗批量 | 选片段 → 选清洗链 → 预估耗时 → 执行（GPU 锁排队）→ 前后指标 | 分离失败：保留原片段并标记 |
| 抽听 | 生成抽样清单 → 逐条播放/标记 → 完成报告 | 未标记完：稍后继续（保存进度） |
| AI 全流程 | 自然语言 → Agent 调工具 → 页面展示每步结果与报告 | 任一工具失败：停止并给出修复建议 |

### 4.4 状态机（数据集/片段）

| 对象 | 状态 | 迁移 |
|---|---|---|
| 数据集 | `draft → importing → slicing → ready → validating → cleaning → exported → archived` | 任一步可取消/失败重试；导出产生版本 |
| 片段 | `raw → sliced → asr_done → aligned → validated(pass/warn/fail) → cleaned → exported → rejected` | 人工可改状态；清洗/重切产生新版本 |

### 5.2 与分离插件（02）的协作

| 场景 | 调用方 | 任务 | 结果 |
|---|---|---|---|
| 去伴奏 | 数据集服务 | 创建 `separate.pymss`（model=bs_roformer_voc_hyperacev2，inputs=片段，stems=[vocals]） | 返回 vocals 路径 → 数据集更新片段 |
| 去混响 | 数据集服务 | `separate.pymss`（dereverb 模型） | dry 片段 |
| 降噪 | 数据集服务 | `separate.pymss`（UVR-DeNoise-Lite 等） | 降噪片段 |
| 批处理 | 页面 | 数据集清洗向导批量建子任务 | 统一 GPU 锁队列，失败不阻塞 |

- 【决策】数据集服务**不直接加载 pymss**，只通过 Gateway 建分离任务并等待；两服务可分别升级/重启。
- 【决策】清洗产物写 `datasets/<id>/cleaned/<version>/...`，不覆盖原片段；片段记录 `cleaned_from` 关联。

## 9. 错误处理 / 降级 / 性能

### 9.1 错误处理原则

1. **不破坏源数据**：所有操作产生新片段/新版本；删除只作用于数据集副本，不动用户源文件。
2. **局部失败不阻塞整集**：单片段失败标红并继续，导出时默认排除 `fail` 状态（可配置为包含并标注）。
3. **指标缺失可降级**：Tier1 模型未下载/加载失败 → 只跑 Tier0，报告标注「未启用」。
4. **可复现**：每个任务记录工具版本、模型版本、参数、输入 sha256。
5. **脏数据可退回**：版本快照保证「清洗不如原片」时可回退（重新导出旧版本）。

### 9.2 降级链

| 场景 | 降级策略 |
|---|---|
| ASR GPU 不可用 | 自动切 CPU（faster-whisper int8/float32），预计 RTF 升 2–5× |
| ASR 模型过大/OOM | 降模型（large→medium→small）并提示精度下降 |
| FunASR 安装失败 | 回退 faster-whisper；记录原因 |
| 对齐引擎失败（TIFA 不可用） | 回退 WhisperX（语音）/MFA（音素级）；仍失败→标 `align_failed` |
| Tier1 模型加载失败 | 跳过该指标，报告标注；不阻断导出 |
| 清洗（分离子任务）失败 | 保留原片段，标 `clean_failed`；可单独重试 |
| 磁盘不足 | 阻止任务并给出清理建议（缓存/旧版本/导出） |
| 视频抽音轨失败 | 提示安装/更新 ffmpeg；跳过该文件 |

### 9.3 长音频/大批量

| 场景 | 策略 |
|---|---|
| 1–3 小时录音 | 分块处理（导入按文件、切片按 10 分钟窗口流式）；ASR 分段 + 合并；进度按块 |
| 数百个文件 | 批量任务串行（默认并发 2 CPU/1 GPU）；失败汇总；可断点续跑（按已完成片段跳过） |
| SVS 1–3 小时标注 | 对齐分批（每批 20–50 句）；失败重试；导出前统一校验 |
| 大模型 ASR | 预下载 + 预热；单次加载复用（服务常驻） |

- 【推断】性能目标（4080 Laptop 16GB，CPU i9-13900HX）：

| 任务 | 目标 | 备注 |
|---|---|---|
| 元数据探测 | 100 文件 ≤ 30 s | 只读头部 |
| 切片（静音/VAD） | ≥ 10× 实时（CPU） | 单线程可接受 |
| ASR（faster-whisper medium，GPU） | RTF ≤ 0.3（10 分钟音频 ≤ 3 分钟） | large-v3 约 0.5 |
| ASR（CPU，small/int8） | RTF ≤ 1.5 | 降级路径 |
| 对齐（TIFA/WhisperX，GPU） | ≤ 0.5× 音频时长 | 批量 |
| Tier0 质检 | ≥ 20× 实时（CPU） | 纯信号指标 |
| Tier1（DNSMOS/UTMOS，GPU） | ≥ 10× 实时 | 模型小 |
| 清洗（去混响，pymss） | 见插件 02 §9.4 | 经 GPU 锁 |
| 导出（10 分钟数据集） | ≤ 30 s | IO 为主 |

### 9.4 隐私与日志

- 服务日志：`AMS_HOME\logs\services\dataset\YYYY-MM-DD.log`（按天滚动；文本内容默认不写日志，只记长度/哈希）。
- 任务日志：`datasets/<id>/logs/<job_id>.json`（参数/事件/耗时/错误；文本脱敏可选）。
- 诊断包：版本、模型清单、任务统计、最近 200 行日志；**不含音频与完整转写文本**（可勾选包含）。

- 数据集输出可能包含原始音频片段：导出/分享前提示「确认拥有声音与内容权利」。
- 不内置任何第三方数据集；不提供爬取/下载工具。
- 训练数据版权（歌词/伴奏）由用户负责；应用只提供格式与工具。

1. **数据集引用**：`{ dataset_id, version, manifest_sha256, kind, target_backends }`；下游训练必须记录该引用。默认走「引用快照」（不复制音频），导出目录仅用于离线/跨机/其他工具。
