## 0. 一页结论

| 维度 | 结论 |
|---|---|
| 定位 | 给“换声/合成/分离/配音/混音”产物做**客观量化 + A-B 盲听 + 批量回归**：回答“这条结果到底行不行、哪里不行、比上一版好还是差” |
| P0 指标 | 无参考：DNSMOS P.835（SIG/BAK/OVRL）、UTMOS22、响度/真峰值/削波、F0 统计；有参考：说话人相似度（ECAPA cosine）、F0 RMSE/RPA、ASR 回读 CER/WER；分离 SDR/SI-SDR（需参考 stem） |
| 有/无参考 | **有参考**指标需要“目标人声/参考 stem/参考文本”；缺失时标 `N/A` 而非报错；无参考指标永远可算 |
| 评测对象 | 换声后音频、TTS/配音片段、SVS 干声、分离 stem、混音成品；可按“单文件/整个工程/一批实验”三种粒度 |
| A-B 盲听 | 内置 ABX（听得出/听不出）与 5 级偏好评分（MUSHRA-lite）；随机化顺序、隐藏系统名、记录用时与一致性 |
| 阈值与门禁 | 每指标可配 `warn/pass/excellent` 阈值；支持 hard gate（硬指标不达标判 fail）与加权综合分；可作训练/换源流水线的质量门 |
| 架构 | 独立 `service.evaluator`；模型（DNSMOS/UTMOS/ECAPA/ASR/F0）按需下载并校验 sha256；默认 CPU、GPU 可选且遵守 00 第 8 节 GPU 锁 |
| 联动 | 训练完成自动评测（产出 UVP `training/metrics.json`）、换源/合成/混音完成可选自动评测、结果写 project 时间线 |

【决策】评测结果只“给证据与阈值结论”，不替用户做“好不好听”的最终判断；A-B 盲听为主观补充。
【决策】SDR 只在提供参考 stem 时计算；否则明确 `N/A`，不允许用“估计参考”冒充。
【决策】评测默认 CPU 执行（小模型可跑），GPU 加速需在任务声明并遵守 GPU 锁；评测不与训练抢显存。
【待定】是否内置 PESQ/STOI、是否引入众包评分导入（见 13.2）。

## 1. 目标与非目标

### 1.1 目标

| # | 目标 | 验收口径 |
|---|---|---|
| G1 | 换声/合成/分离质量可量化 | 一条音频 60 s 内出全部 P0 指标；报告含数值 + 阈值结论 |
| G2 | 能判断“这一版比上一版好不好” | 两版对比：指标差值与 A-B 偏好统计；结论可复现 |
| G3 | 训练/换源流程可自动回归 | 训练完成自动评测并写 `metrics.json`；可配置“不达标阻断发布” |
| G4 | 支持批量实验 | 一次评测 N 条（默认 ≤50），产出汇总表（均值/中位数/最差项） |
| G5 | 主观听感有据可查 | ABX + 5 级评分；导出评分记录与一致率 |
| G6 | 指标可解释 | 报告给出“指标含义 + 本次数值 + 建议动作”，AI 可引用但不可编造 |

### 1.2 非目标

| # | 非目标 | 原因/去向 |
|---|---|---|
| N1 | 替代人耳/专业审听 | 客观指标只作参考；最终发布判断仍靠人 |
| N2 | 模型训练/调参 | 属 trainer/convert 插件；本插件只出评测与建议 |
| N3 | 云端上传/众包评测 | 隐私与成本；全本地，P2 再评估导出评分包 |
| N4 | 版权/深伪/侵权检测 | 法务与内容风控另立专题，不在本期 |

### 4.2 报告布局要素

- 结论横幅：通过/警告/失败 + 未达标项数量（red/yellow/green）。
- 指标表：指标、本次值、阈值、结论、上版值、趋势箭头、权重。
- 缺失项说明：因缺参考 stem/文本而 N/A 的指标单列（避免误读为 0 分）。
- 复现信息：模型清单+版本、随机种子（若有）、阈值模板版本、耗时、服务版本。

### 4.3 A-B 盲听交互

| 环节 | 规则 | 目的 |
|---|---|---|
| 建任务 | 选 2–4 个系统 + 若干句；句级随机顺序 | 减少顺序偏差 |
| 播放 | 响度对齐（默认 -18 LUFS 监听） | 避免“响=好” |
| ABX | 先听 A/B，再听 X，选“X=A/B” | 检测可分辨性 |
| 偏好 | 5 级（-2…+2）+ 可写备注 | 主观量级 |
| 汇总 | 偏好均值、ABX 正确率、置信区间（P1） | 结论可统计 |

### 4.4 状态与异常

| 状态 | 表现 | 处理 |
|---|---|---|
| 空 | “新建评测 / 从任务结果评测”引导 | 预填工程与目标音源 |
| 指标 N/A | 灰色 + 原因（缺参考 stem/文本） | 提供补参考入口 |
| 模型缺失 | 指标行标“模型未下载” | 引导下载/校验（sha256） |

### 5.2 指标定义（P0）

| 指标 | 参考需求 | 定义/口径 | 实现（版本/许可） | 方向 |
|---|---|---|---|---|
| DNSMOS SIG/BAK/OVRL | 无参考 | P.835 人声质量三子分（1–5）；OVRL 为主 | dnsmos-torch-native（MIT + 权重 CC-BY-4.0） | ↑ |
| UTMOS22 | 无参考 | 自然度 MOS 预测（1–5） | utmos22-torch-native（MIT，参考 tarepan/SpeechMOS v1.2.0） | ↑ |
| 说话人相似度 cos | 需目标/参考音频 | ECAPA-TDNN embedding 余弦；同人越接近 1 | speechbrain（Apache-2.0）+ ECAPA 权重【待核实模型卡】 | ↑ |
| F0 RMSE | 需参考人声或同源 F0 | 两轨 F0 曲线在浊音帧上的均方根误差（cents） | pyworld（MIT）+ 可选 FCPE | ↓ |
| RPA@50cents | 需参考 | 音高准确率：偏差 ≤50 cents 的帧占比 | 同上 | ↑ |
| CER / WER | 需参考文本 | ASR 回读文本与参考文本的编辑距离比 | faster-whisper 1.2.1（MIT）+ jiwer（Apache-2.0）；FunASR 1.4.16（MIT）备选 | ↓ |
| SDR / SI-SDR | **需参考 stem** | BSSEval v4：帧级 SDR，静音帧剔除后中位/均值；SI-SDR 为尺度不变变体 | museval（MIT）/ 自研对齐 + torchmetrics（Apache-2.0） | ↑ |
| 集成响度 / 真峰值 | 无参考 | ITU-R BS.1770-4；真峰值 4× 过采样 | pyloudnorm 0.2.0（MIT） | 达标 |

### 5.3 默认阈值与分级（按场景，均可覆盖）

| 场景 | 指标 | 合格（pass） | 良好 | 优秀 |
|---|---|---|---|---|
| 换声/翻唱 | 相似度 cos | ≥ 0.75 | ≥ 0.82 | ≥ 0.88 |
| 换声/翻唱 | DNSMOS OVRL | ≥ 3.0 | ≥ 3.3 | ≥ 3.6 |
| 换声/翻唱 | F0 RMSE（cents） | ≤ 50 | ≤ 35 | ≤ 25 |
| TTS/配音 | CER（中） | ≤ 5% | ≤ 3% | ≤ 2% |
| TTS/配音 | DNSMOS OVRL | ≥ 3.0 | ≥ 3.3 | ≥ 3.5 |
| TTS/配音 | 相似度 cos | ≥ 0.72 | ≥ 0.80 | ≥ 0.86 |
| SVS/填词 | F0 RMSE（cents） | ≤ 50 | ≤ 30 | ≤ 20 |
| SVS/填词 | RPA@50cents | ≥ 0.85 | ≥ 0.92 | ≥ 0.96 |
| 分离 | SDR（人声） | ≥ 6 dB | ≥ 9 dB | ≥ 12 dB |
| 母带 | 真峰值 | ≤ -1 dBTP | ≤ -1.5 | ≤ -2 |

【推断】以上阈值为“可用/良好/优秀”的工程起点，来源为调研 §6.4 与社区经验；必须在第 11 章黄金样本上校准后再发布，且允许用户按场景覆盖。
【风险】不同模型/音源域会让相似度绝对值漂移（ECAPA 同人 0.75 不是硬标准），报告必须显示“同批次相对排序”，避免跨批次绝对值比较。

### 5.4 综合评分与门禁

- 每个指标定义 `warn/pass/excellent` 三档 + `weight` + `required`（是否硬门禁）。
- 结论：任一 required 指标低于 pass → 整体 `fail`；无 required 失败但有 warn → `warn`；全部 ≥ pass → `pass`。
- 综合分（0–100）：按指标线性映射（pass 档记 60–80，excellent 记 100）后按 weight 加权；仅用于排序，不用于“发布判定”。
- 缺失指标：N/A 不计入分母；若 required 指标 N/A，整体结论 `incomplete`（需补参考）。
- 阈值模板版本化：模板 id + version 写入报告，避免历史报告被新阈值“改写结论”。

### 5.6 模型管理与 GPU/CPU 策略

| 项 | 策略 |
|---|---|
| 模型来源 | 随服务打包“小模型”（DNSMOS/UTMOS）；ECAPA/ASR 按需下载（ModelScope/hf-mirror，00 第 11 节镜像） |
| 校验 | 每个模型目录含 `manifest.json`（name/version/sha256/source/license），启动与使用前校验 |
| 存储 | `AMS_HOME/models/eval/<name>/<version>/`；可离线导入 |
| 执行设备 | 默认 CPU；任务参数 `device: auto|cpu|cuda`；cuda 需先取 GPU 锁（00 第 8 节） |
| 并发 | 单服务内指标并行 2 路；批量任务逐条串行（避免显存/CPU 抖动） |

### 5.7 计算流水线与缓存

1. 预检：文件存在/可解码/时长/采样率/声道/静音/削波；不合法项直接标记失败原因。
2. 规范化：按指标需求生成 16 kHz 单声道、48 kHz 立体声、原采样三份内存视图（不写盘）。
3. 参考对齐：SDR 需参考 stem 与估计 stem 样本对齐（同长/同 SR）；F0 需同源参考。
4. 指标计算：逐指标独立 try/catch，失败记 `skipped` + 原因，不拖垮整批。
5. 汇总：逐条 + 全局（均值/中位/最差/标准差）；写 `results.json`。
6. 缓存：key = `sha256(audio) + metric + impl_version + params`，命中直接复用（CPU 密集指标尤其重要）。

## 6. 数据模型与目录

### 6.2 eval.json 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| eval_id / project_id | string | 评测 id / 所属工程 |
| created_at / finished_at | string | ISO 8601 |
| kind | string | single / batch / ab / dataset |
| items[] | array | 评测条目（见 6.3） |
| metrics | string[] | 请求的指标集合 |
| thresholds | object | 阈值模板 id/version/覆盖值 |
| refs | object | 参考 stem/文本/目标音源路径或 artifact id |
| device / engine | string | cpu/cuda；服务版本+模型版本 |
| conclusion | string | pass / warn / fail / incomplete |

### 6.3 单条结果字段（items[] / results[]）

| 字段 | 类型 | 说明 |
|---|---|---|
| item_id | string | 条目 id（稳定） |
| source | object | path/相对路径、sha256、duration、sr、channels |
| target_voice | object? | 目标音源 id + hash（相似度用） |
| ref | object? | 参考 stem/参考文本；缺失则相关指标 N/A |
| metrics | object | 各指标数值 + 子分（dnsmos{sig,bak,ovrl,p808}） |
| status | string | ok / skipped / failed |
| reasons | string[] | 跳过/失败原因（缺参考、解码失败、模型未装…） |
| conclusion | string | 本条结论（按阈值） |

### 6.4 阈值模板

| 字段 | 说明 |
|---|---|
| template_id / version | 模板标识与版本 |
| metrics.<name>.warn/pass/excellent | 三档阈值（方向由指标定义决定） |
| metrics.<name>.weight | 综合分权重 0–1 |
| metrics.<name>.required | 是否硬门禁 |
| applies_to | singing / tts / svs / separation / mastering |
| notes | 校准依据、适用模型/数据集 |

### 6.5 与 project / UVP 的关系

- 评测作为 project 时间线的一步（step.type=`eval`），记录输入产物、阈值模板、结论；与训练/换源 Job 通过 job_id 关联。
- 训练后评测结果写入 UVP `training/metrics.json` 的 `metrics` 字段（与调研 §8.3 对齐），作为音源包元数据。
- 评测报告不复制大音频，只引用工程内相对路径 + hash；跨机器迁移后按 hash 校验，缺失则标 `stale`。
- 与 08 混音：混音渲染后可触发 `mastering` 场景评测（响度/真峰值/DNSMOS），结果回显在混音页响度表旁。

### 7.2 Job `eval.run` 参数

| 参数 | 必填 | 说明 |
|---|---|---|
| project_id | 是 | 工程 id（写入该工程 eval/） |
| items[] | 是 | `{id, audio, target_voice?, ref_stem?, ref_text?}`；单批 ≤50 |
| metrics | 是 | 指标集合；按场景模板给默认值 |
| thresholds | 否 | 模板 id+version，或内联覆盖 |
| device | 否 | `auto|cpu|cuda`；cuda 需 GPU 锁 |
| ab | 否 | `{enable, systems[], items[], mode: abx|pref}` |
| gate | 否 | true 时结论 fail 触发 warning/阻断（由调用方决定） |

### 7.3 SSE 事件（`GET /jobs/{id}/events`）

| 事件 | 载荷 | 说明 |
|---|---|---|
| progress | `{percent, stage, done, total}` | stage：precheck/decode/metrics/sdr/asr/report |
| warning | `{code, message, item_id?}` | N/A、跳过、模型降级 |
| artifact | `{artifact_id, kind, path}` | report/results/ab 产物 |
| status | `{status, error?}` | succeeded/failed/cancelled |

### 7.4 错误码

| 码 | 含义 | 处理 |
|---|---|---|
| EVAL_E_001 | 音频不可解码/为空 | 标 failed + 原因，不中断整批 |
| EVAL_E_002 | 参考缺失（stem/文本/目标音源） | 相关指标 N/A + warning，非错误 |
| EVAL_E_003 | 指标模型未安装 | 指标标 skipped；引导下载 |
| EVAL_E_004 | 模型校验失败（sha256/损坏） | 拒绝使用，提示重新下载 |
| EVAL_E_005 | 显存/CPU 资源不足 | 降级 CPU 或降低并行；warning |
| EVAL_E_006 | 报告写入失败（磁盘/权限） | failed + 保留 results.json |

### 7.5 并发、超时与缓存

- 缓存键：`sha256(audio)+metric+impl_version+params`；同键复用时报告标注 `cached`。
- 同一工程批量串行；不同工程可并行（全局并发默认 2）。
- 超时：`条目数 × 2 min + 5 min`（ASR/SDR 条目可按 3 min）；超时标 failed。
- 取消：杀进程树，清理临时片段；已算完的条目结果保留（可续跑）。
- 幂等：同 items + 指标 + 模板 + 模型版本命中已完成评测时，默认返回既有结果（可 `force=true` 重算）。

### 8.2 AI 解读边界

- 解释只能引用报告中的数值、阈值、模型版本；不得编造或替换数据。
- “建议”必须绑定证据（哪项、差值多少、可能原因、建议动作），并标注【建议】。
- 不得声称“达到商业级/可发布”；结论只到 pass/warn/fail/incomplete。

### 8.3 Skills

- `ams-评测解读`：读报告 → 排序未达标项 → 给 1–3 条建议 → 生成对比表（新增）。
- `ams-混音质检`（08 引用）：渲染后触发 mastering 场景评测。
- `ams-音源炼制SOP`（01 引用）：训练后自动跑回归评测。
- 输出固定小节：结论、未达标项、证据、建议、复现信息。

## 9. 错误处理/降级/性能指标

### 9.1 错误处理

| 类别 | 策略 |
|---|---|
| 单条失败 | 记 failed + 原因，继续其他条目；批次结论含失败数 |
| 模型/权重问题 | 校验失败即拒绝；不降级到“别的模型”冒充同指标 |

### 9.2 降级矩阵

| 缺失/异常 | 降级行为 | 用户可见 |
|---|---|---|
| GPU 不可用 | device=auto 回落 CPU；耗时提示 | 报告标 `device=cpu` |
| ASR 模型未装 | CER/WER N/A；其余指标照算 | 指标行提示“需下载 ASR” |
| 参考 stem 缺失 | SDR/SI-SDR N/A | 提示补参考 stem |
| ECAPA 权重缺失 | 相似度 N/A（不用其他 embedding 冒充） | 提示下载/离线导入 |
| 服务离线 | 页面只读历史报告 | “服务未启动”+ 重启 |

### 9.3 性能目标（CPU：i9-13900HX；GPU 可选）

| 指标 | 目标 |
|---|---|
| 单条 60 s 音频：DNSMOS+UTMOS+相似度+F0 | ≤ 60 s（CPU） |
| 单条 ASR 回读（60 s 中文） | ≤ 90 s（CPU，faster-whisper small/medium 按配置） |
| 批量 50 条 × 60 s（全套指标） | ≤ 15 min |

## 11. 测试与验收

### 11.1 指标一致性用例

| 用例 | 构造 | 期望 |
|---|---|---|
| SDR 解析解 | 估计 = 参考 + 已知功率噪声 | 与公式误差 ≤ 0.1 dB |
| F0 | 已知频率正弦合唱/滑音 | RMSE ≤ 5 cents（同算法对比） |
| CER | 已知参考/假设文本对 | 与 jiwer 一致（±0） |
| DNSMOS/UTMOS | 官方示例音频 | 与官方实现 ≤ 0.05 / ≤ 0.1 |
| 响度 | EBU R128 测试信号 | ±0.2 LU；真峰值 ≤ 0.1 dB |
| 鲁棒性 | 单声道/44.1k/静音/削波/0.5 s 短音频 | 不崩溃；N/A/失败原因明确 |

### 11.2 验收清单

- [ ] P0 指标全部可算；无参考指标在无任何参考时也可出报告。
- [ ] 有参考指标缺失时正确标 N/A，且不影响整体结论（`incomplete`）。
- [ ] 阈值模板可保存/版本化；历史报告结论不随新模板变化。
- [ ] 批量 50 条不超时；缓存命中生效；失败条目可单独重跑。
- [ ] A-B 盲听顺序随机、隐藏系统名、评分可导出；一致率可计算。
