## 2. 三条管线（速查）

### 管线 A：DiffSinger 可编辑主路径（产品主形态）
~~~text
旋律来源（MIDI / 分离人声转谱 / 手绘）
  → 音符切分 + F0（GAME；或直接用 MIDI）
  → 人工校正（最小 piano-roll）
  → 歌词 → pypinyin/jieba 注音 → 音节↔音符分配（自动+拖动）
  → 生成 .ds（音符/音素/时长/滑音，可选 variance 参数）
  → DiffSinger 声学 ONNX（+ variance ONNX）
  → NSF-HiFiGAN 声码器 ONNX → 干声
  →（可选）SoulX-Singer-SVC / RVC 换目标音色
  → 与伴奏对齐/混音 → 导出
~~~
- 输入：MIDI/.ustx/音频；输出：干声 wav + 工程；许可：Apache/MIT（声码器 AGPL 注意）；成本：自研渲染+编辑器约 2–4 人周【推断】。

### 管线 B：SoulX-Singer 零样本（最快出音）
~~~text
歌词 + MIDI/音符 + 10s 音色参考
  → SoulX-Singer（score 模式）
  → 干声 → 混音
~~~
- 无训练；Apache-2.0；输入为其内部 metadata JSON（歌词+音符+F0）；音色相似度需 A/B。

### 管线 C：YingMusic-Singer-Plus 改词（已有原曲）
~~~text
原曲 → 人声分离 → 旋律参考 clip + 原词 + 新词
  → YingMusic-Singer-Plus（--melody_audio + --target_text）
  → 新干声（保旋律）→ 混伴奏
~~~
- 一条命令；CC BY 4.0 + VAE Stability 条款；不是编辑器级可控，适合草稿/批量。

## 3. 编辑器最少交互（MVP 10 项）

| # | 交互 | 说明 |
|---|---|---|
| 1 | 导入/生成旋律 | MIDI/ustx/上传歌曲自动转谱 |
| 2 | 歌词输入与分句 | 整段粘贴→自动分词注音→按音节数分配；“|”分句 |
| 3 | 音符级编辑 | 拖动音高/时长、增删、连音、休止/呼吸（SP/AP） |
| 4 | 音节分配修正 | 一字多音/多字一音，拖拽换位 |
| 5 | 试听与局部重渲 | 单句/整段渲染，缓存与增量 |
| 6 | 音素面板 | 声母/韵母时长、替换音素、查看序列 |
| 7 | 表情控制 | 气声/张力/能量 3 滑杆；进阶颤音（深度/频率/延迟） |

## 5. 数据格式速查

### 5.1 .ds（DiffSinger 推理输入，JSON 数组）
| 字段 | 含义 |
|---|---|
| offset | 该段起始时间（秒） |
| text | 以空格分词的歌词（含 AP/SP） |
| ph_seq / ph_dur / ph_num | 音素序列 / 每个音素时长（秒）/ 每个词含几个音素 |
| note_seq / note_dur / note_slur | 音名（如 C4、rest）/ 音符时长 / 连音标记 0/1 |
| f0_seq 等 | 可选参数曲线（OpenUtau 导出时带 timestep） |

样例：DiffSinger 仓库 samples/ 下 7 个中文 .ds（如 03_撒娇八连.ds 含 AP/SP 与滑音）。

### 5.2 声库 dsconfig.yaml 关键字段（OpenUtau 解析口径）
phonemes、acoustic、vocoder、speakers、hiddenSize、useKeyShiftEmbed、useSpeedEmbed、useEnergyEmbed、useBreathinessEmbed、useVoicingEmbed、useTensionEmbed、use_lang_id、dur、dur_type、linguistic、pitch、variance、predict_dur、predict_energy、predict_breathiness、predict_voicing、predict_tension、use_expr、use_note_rest、sample_rate。

### 5.3 本产品中间格式
| 文件 | 关键字段 |
|---|---|
| melody.json | note_id、start、dur、midi、lyric、slur、source |
| lyrics.json | sentence_id、word、char、pinyin、phonemes[]、note_ids[]、time[] |
| render.json | engine/版本、声库名+hash、参数、候选、耗时、显存 |
| voicebank.json（旁车，可选） | 名称/来源/许可/署名/hash/解析缓存（删除不影响使用） |
