## 0. 一页结论

**定位**：把“一首曲子的旋律 + 一个音源 + 一段新词 → 唱出来”做进 AMS：默认是**有钢琴卷帘的最小填词编辑器**，底层用 DiffSinger 本地渲染；同时提供两条“零训练捷径”（SoulX-Singer 零样本、YingMusic-Singer-Plus 保旋律改词）作为加速与兜底。

| 结论项 | 内容 |
|---|---|
| **【决策】主路径** | 路线 A：DiffSinger（Apache-2.0）ONNX 声学+方差+NSF-HiFiGAN 声码器，本机无头渲染；声库用户导入 |
| **【决策】加速/兜底** | 路线 B：SoulX-Singer（Apache-2.0）零样本；路线 C：YingMusic-Singer-Plus（CC BY 4.0）保旋律改词 |
| **【决策】音色顺序** | SVS 干声 → RVC（已训练音源）/SoulX-Singer-SVC（零样本）换音色；**禁止反过来** |
| **【决策】自研核心** | 无头渲染器、音节↔音符分配器、最小编辑器、声库许可元数据、混音对轨；约 8–11 人周单干 / 4–6 人周双人【推断】 |
| **【决策】P1 不做** | DiffSinger 声库训练（P2）、实时演唱、整曲生成（P3）、SynthV 级精修 |
| **【风险】最大不确定性** | 开源 SVS 音质与中文吐字 / 零样本音色相似度 / 自研编辑器体验，需 S6、S7 两个 spike 先验证（见 §11、00 第 16 节） |
| **许可总策略** | 代码 MIT/Apache 类可直接用；AGPL（声码器/旧引擎）只“调用用户本地文件”或不分发；社区中文声库默认按**非商用**处理，不随包分发 |

## 1. 目标与非目标

### 1.1 目标（P1 简版）
1. 用户可把 **MIDI / .ustx / 已有歌曲** 变成一条“旋律轨（音符+音高）”；
2. 输入中文歌词，自动 **分词/注音/分句** 并 **分配到音符**，允许手动修正；
3. 用 **本地 DiffSinger 声库** 渲染出 **干声**，能试听、局部重渲、导出；
4. 能用 **零样本（SoulX）** 或 **改词（YingMusic）** 两条捷径在不训练声库的情况下出音；
5. 能把干声 **换音色（RVC/SVC）** 并与伴奏 **对齐/混音**，产出可发布成品；
6. 全流程走 **Gateway 任务**、产物进 **工程目录**，可复现、可回滚。

### 1.2 非目标（明确不做 / 后置）
| 项 | 说明 | 阶段 |
|---|---|---|
| DiffSinger 声库训练（自训 SVS 音色） | 需要 1–3h 标注数据 + 1–3 天训练；放在“数据集/炼制”插件里做 | P2 |
| 实时演唱/实时变声 | 与实时变声插件不同，演唱是离线渲染 | 不做 |
| 整曲生成（ACE-Step/YuE2） | 属于“编曲/整曲兜底”，作为独立能力 | P3 |
| 完整 V 家编辑器（SynthV 级） | 音素级包络、多轨和声、复杂表情脚本 | P2+ 视用户反馈 |
| 商业声库/音源内置 | 见 00 第 1、12 节：应用不分发权重 | 永不 |
| 谱面识别（图片/PDF 曲谱） | OMR 不在范围 | 不做 |

## 2. 目标用户与场景

| 用户 | 场景 | 产品承接 |
|---|---|---|
| 翻唱/二创作者 | 有原曲，想换词、换人声、保留旋律 | 路线 C 快速出草稿 → 路线 A 精修 |
| 原创作者 | 有 MIDI/哼唱旋律，想让人声唱自己写的词 | 路线 A：导入 MIDI → 注音 → 分配 → 渲染 |
| “AI 歌手”爱好者 | 有 RVC 音源（pth+index），想让“自己的音色”唱任意歌 | 路线 A 渲染干声 → RVC 换音色（复用已有音源库） |
| 零基础用户 | 不会乐器，只有一段想要的歌词/风格 | 路线 B 零样本（给参考音色 + 旋律）或 C（给原曲） |

**AI 操作场景（Agent 与用户协作）**：
1. **写词**：用户给主题/情绪，Agent 按“每句音节数 = 音符数”约束写词并给押韵候选；
2. **注音校验**：Agent 检查多音字/儿化/轻声/英文混排，对不确定项列候选让用户点选；
3. **参数建议**：按曲风给“气声/张力/能量/颤音”三档预设（如抒情/流行/说唱）；
4. **排错**：渲染失败/串音/吞字时，Agent 读任务日志 + 音素序列给诊断建议（改哪个音素/时值/音高）。

## 3. 三条路线与选型

### 3.1 路线对照

| 维度 | A：DiffSinger/OpenUtau（主） | B：SoulX-Singer（零样本） | C：YingMusic-Singer-Plus（改词） |
|---|---|---|---|
| 输入 | 音符+歌词（.ds） | 歌词+MIDI/F0+10s 音色参考 | 旋律参考人声+原词+新词 |
| 音色来源 | 声库（用户导入；通用或自训） | 任意参考音频（零训练） | 原唱音色或参考音频 |
| 可控性 | 高（逐音符/音素/参数） | 中（歌词+音符，参数少） | 低（保旋律改词，无音符编辑） |
| 中文 | 好（声库而定） | 好（42k 小时训练） | 好（中英，可翻译） |
| 许可 | Apache-2.0 + MIT；声码器 AGPL【风险】 | Apache-2.0（代码+权重） | CC BY 4.0 + VAE Stability 条款【风险】 |
| 成本 | 需自研渲染/编辑器；声库另备 | 2.7 GiB 权重，推理数秒/句【推断】 | 2.8 GiB 主权重，推理数秒~十几秒/句【推断】 |
| 适用 | 产品主形态：可编辑、可离线、可商用 | “上传音色即用”的快速通道 | 已有原曲的改词草稿/批量 |
| 版本/日期 | DiffSinger v2.5.1（2026-01-08）；OpenUtau 0.1.576.1 Alpha（2026-10-18） | 代码/权重 2026-02-06（arXiv 2602.07803） | arXiv 2603.24589；HF 2026-04 更新 |

### 3.2 推荐产品形态【决策】

**A 为主 + B/C 加速兜底**：
- 默认走 A：用户导入声库 + MIDI/旋律 → 编辑 → 渲染 → 混音；
- 用户没有声库或想先听效果 → B（零样本，10s 参考）；
- 用户只有一首现成歌（带原唱）→ C 先出“改词草稿”，再进 A 精修（歌词/音节数据结构共享）；
- **音色后处理顺序固定**：先用 A/B/C 出“唱对”的干声，再 RVC/SVC 换音色；**先 RVC 再 SVS 不成立**（SVC 输出是音频，不含可用于 SVS 的音素/音符标注）。

### 3.3 不采用的候选（见 SVS 调研）
NNSVS（MIT，2023-10 停更）、VISinger2（无 LICENSE）、NEUTRINO（闭源+日语）、Sinsy（HTS 老栈）、UTAU 原版（闭源）；ACE-Step 1.5/YuE2 仅作为 P3 整曲兜底（YuE2 权重 CC-BY-NC-4.0 禁商用【风险】）。

## 4. 功能清单（P1 简版）

| # | 功能 | 说明 | 验收标准 | 优先级 |
|---|---|---|---|---|
| F1 | 旋律导入 | MIDI / .ustx / .ds 只读导入；解析音符、音高、时长、连音 | 3 种格式各 1 个样例可打开；时间轴正确 | P1 |
| F2 | 旋律提取 | 上传原曲→调用分离器得到人声→GAME/SOME 转谱→可编辑 | 30s 人声转谱耗时 <30s【推断】；音高可人工改 | P1 |
| F3 | 歌词输入与分句 | 整段中文粘贴；支持“|”分句；自动分词 | 100 字歌词 ≤1s 出分句与注音 | P1 |
| F4 | 注音与多音字 | pypinyin 注音；多音字给候选；儿化/轻声/英混提示 | 常用多音字（重庆/银行/音乐等）默认正确；可逐字改 | P1 |
| F5 | 音节↔音符分配 | 自动按音节数分配；一字多音/一音多字；拖动换位 | 自动分配后 ≤20% 需人工修正 | P1 |
| F6 | 最小 piano-roll | 音符增删/拖动音高时长/连音/休止符（SP/AP）；显示音高曲线 | 20 音符编辑不卡顿（≥30fps） | P1 |
| F7 | 渲染与试听 | DiffSinger ONNX 本地渲染；候选 2–4 条；局部重渲 | 首句（5s）GPU ≤3s、CPU ≤15s【推断】 | P1 |
| F8 | 零样本模式 B | 选 10s 参考音频→SoulX 渲染（可选，服务可用时） | 与 A 同一套歌词/音符数据可切换引擎 | P1（可降级） |
| F9 | 改词模式 C | 选原曲/旋律 clip+新词→YingMusic 出干声/混伴奏 | 一条任务产出新干声，旋律主观保持 | P1（可降级） |
| F10 | 音色后处理 | 干声→已有 RVC 音源（convert.rvc）或 SoulX-SVC | 复用音源库；有 A/B 试听 | P1（可选） |
| F11 | 对轨/混音/导出 | 干声与伴奏对轨、增益、响度；导出 wav/工程 | 与混音插件产物一致；LUFS 达标 | P1 |
| F12 | 工程保存/恢复 | project.json 记录输入/参数/产物/引擎版本 | 重开工程可复现上次渲染 | P1 |

**P2 预留**：声库训练（MakeDiffSinger/TIFA 管线）、variance 参数手工曲线、和声/双声部、LRC 导出、批量渲染队列。

## 6. 数据模型与目录

### 6.1 声库目录（svs_voicebanks，见 00 第 6 节）

~~~text
AMS_HOME\svs_voicebanks\<声库名>\
├─ dsconfig.yaml          # 采样率/音素表/模型清单（DiffSinger 契约）
├─ phonemes.txt
├─ dsdict-zh.yaml         # 拼音→音素（可多语言）
├─ acoustic.onnx
├─ variance.onnx          # 可选（音高/能量/气声/张力）
├─ vocoder.onnx
└─ voicebank.json         # 可选旁车：名称/来源/许可/署名/hash/解析缓存（删除不影响使用）
~~~

规则（对齐 00 第 6 节音源库思路）：文件夹名即显示名；必需信息不放在旁车里；应用只做导入/校验/元数据缓存，不修改文件；**不随包分发任何声库**。

### 6.2 工程目录（projects/<id>/singing/，见 00 第 7 节）

~~~text
projects\<project-id>\
├─ source\                # 原始音频/视频、MIDI 引用
├─ stems\                 # 分离结果（vocals/instrumental）
├─ vocals\                # 换声后的人声（RVC）
└─ singing\
   ├─ melody.json         # 音符：start/dur/midi/lyric/slur(可选 source)
   ├─ lyrics.json         # 句子/词/字/拼音/音素/音符分配/时间戳
   ├─ score.ds            # DiffSinger 推理输入（由 melody+lyrics 生成）
   ├─ renders\            # 每次渲染的 wav + render.json（参数/引擎/耗时/seed）
   ├─ edits.json          # 用户手改记录（音素/参数/曲线），用于重渲与回滚
   └─ export\             # 干声/混音/工程的导出产物
~~~

### 6.3 关键中间格式

| 文件 | 作用 | 关键字段 | 备注 |
|---|---|---|---|
| melody.json | 旋律轨（本产品中间格式） | note_id、start(拍/秒)、dur、midi、lyric、slur、source | 与 MIDI 互转；保留原始来源信息 |
| lyrics.json | 歌词与分配 | sentence_id、word、char、pinyin、phonemes[]、note_ids[]、time[] | AI 校验/编辑都改这里 |
| score.ds | DiffSinger 推理输入 | offset、text、ph_seq、ph_dur、ph_num、note_seq、note_dur、note_slur | 现场 A 产物，不对外承诺稳定 |
| .ustx | OpenUtau 工程（可选导入/导出） | 轨道/音符/歌词/音素 | 用于“专业用户进 OpenUtau 精修” |
| render.json | 渲染记录 | engine/版本、声库名+hash、参数、候选、耗时、显存 | 写入 project.json 引用，保证可复现 |

> 【待定】是否把 OpenUtau 的 .ustx 作为**可编辑的工程主格式**（能白拿它的编辑器特性），还是坚持自有 melody.json/lyrics.json（更可控但需自研 UI）。倾向后者，P1 只做 .ustx 只读导入与导出。

## 7. 接口与任务（Gateway）

### 7.1 任务类型（建议加入 00 第 8 节清单；【待定】需 Lead 批注）

| 任务 type | 作用 | 引擎参数 | 典型耗时【推断】 |
|---|---|---|---|
| singing.prepare | 旋律提取/导入 + 注音/分词 + 音节分配 → 生成 score.ds 或零样本 metadata | engine=diffsinger/soulx/yingmusic；mode=import/analyze/lyrics/assign | 秒级~30s |
| singing.render | 渲染干声（可候选 2–4 条） | engine + 声库/参考音频 + 参数 | 首句 GPU 数秒 / CPU 十几秒 |
| singing.export | 对轨+响度+导出（或转交 mix.render） | 目标格式/LUFS | 秒级 |
| convert.svc【待定】 | SoulX-Singer-SVC 零样本换音色（区别于 convert.rvc） | 参考音频/源干声 | 数秒/句 |

> 00 第 8 节已有 convert.rvc、mix.render、train.rvc 等；本节新增 3 个 singing.* 与 1 个 convert.svc，需在 00 第 8 节增补后方可实施（【待定】D1）。

### 7.2 接口要点（沿用 00 第 8 节）
- 创建任务：POST /jobs {type, params, project_id}；查询/取消/SSE 事件同 00；
- 产物：GET /jobs/{id}/artifacts → 每个候选 wav 一条 artifact（含 engine/声库 hash/参数摘要）；
- GPU 锁：singing.render/convert.svc 申请 GPU 锁；CPU 降级模式标记为 CPU 任务（可与其它 CPU 任务并行）；
- 可恢复：P1 支持“单句失败重试”，整段不要求断点续训。

### 7.3 工具清单（Host 插件注册，命名遵循 00 第 9 节）

| 工具 | 作用 | 对应任务 |
|---|---|---|
| music_singing_import | 导入 MIDI/.ustx/.ds/原曲，建 melody 轨 | singing.prepare(mode=import) |
| music_singing_analyze | 旋律提取（原曲→人声→MIDI） | singing.prepare(mode=analyze) |
| music_singing_lyrics | 歌词解析/注音/分句/多音字候选 | singing.prepare(mode=lyrics) |
| music_singing_assign | 音节↔音符自动分配 | singing.prepare(mode=assign) |

## 8. AI 工具与技能（Agent 协作）

| 场景 | 工具/能力 | 约束 |
|---|---|---|
| 写词 | 提示词模板（每句音节数=音符数、押韵、主题）→ 逐句写入 lyrics.json | 生成后必须通过“音节数校验”才可提交 |
| 注音校验 | pypinyin 结果 + 多音字候选表；Agent 只做建议，用户点选 | 不确定项必须人工确认 |
| 参数建议 | 曲风→{气声,张力,能量,颤音} 预设映射表 | 只给 3 档，不做连续曲线自动美颜 |
| 试听筛选 | 多候选取 F0 稳定性/ASR CER 排序，推荐 1–2 条 | 最终由人听感确认（00 第 1 节本地优先，ASR 本地跑） |
| 排错 | 读任务日志 + 音素序列 + 声库信息给建议（音素缺失/时长过短/参考音频质量） | 不自动改用户工程，给“应用建议”按钮 |

**Skills（随插件分发）**：【待定】新增 ams-填词成歌工作流（00 第 9 节 Skills 列表需增补），内容：准备旋律 → 写词/注音 → 分配 → 渲染 → 音色 → 混音 → 导出，含常见错误与许可提示。

## 9. 错误处理 / 降级 / 性能

| 情况 | 处理 | 指标 |
|---|---|---|
| 声库缺失/损坏 | 阻止渲染，提示导入；列出缺失文件 | 错误码 E_SVB_MISSING |
| 音素表缺失（歌词含未定义音素） | 定位到字/音素，给替换建议；不静默丢字 | E_PHONEME_UNKNOWN |
| 歌词音节数 ≠ 音符数 | 提示三种修复（增删音符/合并/拆分），允许强制渲染 | E_SYLLABLE_MISMATCH |
| 显存不足 | 自动降级：ONNX CPU 模式 / 减少候选 / 提示关闭其它任务 | GPU 锁释放，任务标记 degraded |
| 零样本服务不可用 | B/C 模式置灰，A 路线不受影响 | 降级不阻塞 |
| 上游漂移（声库/模型升级） | service 版本锁定 + 声库 hash 校验 + 回退开关 | 版本不匹配时警告 |
| 性能目标（本机 RTX 4080 Laptop 16GB【推断】） | A：首句 GPU ≤3s、CPU ≤15s；B/C：每句 3–15s；混音实时级 | 见 §11 验收 |

| 项 | 风险/策略 | 标注 |

| YingMusic-Singer-Plus | 代码/权重 CC BY 4.0（需署名）；VAE 走 Stability AI Community License（商用有门槛）→ 默认标记“非商用/需法务确认” | 【风险】 |
| YuE2/SheetSage2 | 权重 CC-BY-NC-4.0，**仅 P3 研究用，不进 P1** | 【风险】 |
