## 1. 产品定位与范围

- **产品形态**：Windows x64 的**独立 AI 音乐工作站**，自带 Agent（AI 可操作）＋完整图形界面（人可操作），不依赖用户已安装的 DSH，也不依赖系统 Python/Node/CUDA 环境。
- **核心能力**：音源炼制、人声分离、实时变声、歌曲换源、TTS/配音、数据集、音色库、混音母带、评测、项目管理、V 家式填词（后续）。
- **AI 接入**：用户填自己的 DeepSeek API Key（也支持自定义 OpenAI 兼容端点）；本地推理不依赖云端。
- **音源**：**用户自备**；应用不分发任何音源/模型权重；只提供导入、校验、管理与转换工具。
- **平台**：首发且只做 Windows 10/11 x64；N 卡优先（CUDA），兼容 CPU/DirectML 作为降级路径。
- **合规姿态**：开放组件遵守各自许可；音源/版权/声音权由用户负责；应用提供 AI 生成内容标识与来源记录能力。MSVC 转换工具仅处理用户本地文件。

## 2. 代号与命名

- 工作代号：**AMS**（AI Music Studio）。正式产品名未定，后续统一替换；文档中 AMS 仅作技术代号。
- GitHub：`https://github.com/yan-mc`（用户已登录）；仓库一律 `ams-` 前缀。
- npm 作用域：`@ams/`；Python 包前缀 `ams_`；插件 ID 前缀 `ams.`；工具名前缀 `music_`；skill 名 `ams-*`。
- 进程/服务名：`AMS Launcher`、`AMS Kernel`、`ams-gateway`、`ams-svc-<name>`。

## 3. 总体架构与进程模型

~~~text
┌──────────────────────────────────────────────────────────────┐
│ AMS Launcher（Tauri2 + Rust + Vue3）                          │
│ 安装/环境/组件/音色库/更新中心/诊断/任务总览/MSVC 转换器        │
└───────┬───────────────────────────────┬──────────────────────┘
        │ 启动/停止/健康检查              │ 本地 RPC（token）
        ▼                               ▼
┌──────────────────────┐      ┌────────────────────────────────┐
│ AMS Kernel（fork DSH）│      │ AMS Gateway（Python FastAPI）   │
│ Electron 壳+内核运行时 │◄────►│ 任务队列/SQLite/GPU 锁/产物库   │
│ 音乐 Host 插件        │ HTTP │ 服务注册/SSE/日志/鉴权          │
│ 音乐 Client 页面      │      └───────┬────────────────────────┘
│ Skills / Tools        │              │ 拉起/监管
└──────────────────────┘              ▼
                          ┌────────────────────────────────────┐
                          │ 后端服务进程（各自独立运行时）        │
                          │ rvc-train / rvc-infer / voice-changer│
                          │ pymss / gptsovits / tts / diffsinger │
                          │ mixer / evaluator / msvc-converter   │
                          └────────────────────────────────────┘
~~~

**进程归属**：
- 启动器：常驻（托盘），负责安装、更新、启动内核与网关、环境/组件/音色库管理、MSVC 转换；不承载 AI 会话。
- 内核：Electron 应用，承载 DSH 内核 + 音乐插件（Host/Client）+ 页面；由启动器拉起与监管；可单独重启。
- 网关：本地 Python 服务，唯一任务/服务/产物入口；内核插件、页面、启动器、CLI 全部走它；由启动器拉起并保活。
- 后端服务：每个后端一个进程（可多实例按 GPU 锁串行），由网关拉起/监管；各自独立 Python 运行时。

**端口**：网关与后端一律绑定 `127.0.0.1`，端口动态分配并写入 `runtime/ports.json`；调用需带 32+ 字节随机 token（`runtime/gateway.token`）。不监听公网。

## 4. 安装目录与数据目录

安装目录（可升级/可回滚，尽量小）：
~~~text
%LOCALAPPDATA%\Programs\AMS\
├─ Launcher\                 # 启动器（自带更新器）
├─ Kernel\<version>\         # Electron 壳 + dsh 运行时（整包一个版本单元）
├─ Tools\                    # 7z/ffmpeg/VB-Cable 安装器/VST 等（按组件版本）
└─ Uninstall.exe
~~~

数据目录 `AMS_HOME`（默认 `%LOCALAPPDATA%\AMS`，首次启动可改到空间大的盘）：
~~~text
AMS_HOME\
├─ config\                   # launcher 设置、组件状态、state.db
├─ profiles\music\           # DSH profile：profile 配置、patch、plugins(node_modules)
├─ runtime\                  # 各服务 Python 运行时 + ports.json + gateway.token
├─ services\                 # 各后端服务程序/版本（python wheel 或 便携包）
├─ voices\                   # ★ 音源库（严格格式见第 6 节）
├─ tts_voices\               # TTS 音色包（GPT-SoVITS/Qwen 等，独立格式）
├─ svs_voicebanks\           # SVS 声库（DiffSinger/OpenUtau，P1）
├─ datasets\                  # 数据集版本化快照（不可变，数据集工作室维护）
├─ models\                   # 后端基础模型缓存（pymss/RVC 底模/HuBERT/声码器等）
├─ projects\                 # 作品工程（见第 7 节）
├─ cache\                    # 下载缓存、临时文件、缩略图
├─ logs\                     # 启动器/内核/网关/服务日志（按天滚动）
├─ updates\                  # 更新暂存、快照、回滚包
└─ backups\                  # 配置/索引/工程备份（backups/projects/）
~~~

规则：安装目录只放程序；用户资产（音源/模型/工程）只在 AMS_HOME；删除安装目录不丢资产。提供“便携模式”（AMS_HOME 放在程序旁）。

## 5. 组件清单与版本边界

| 组件 ID | 内容 | 版本 | 更新方式 | 更新频率 |
|---|---|---|---|---|
| `launcher` | 启动器本体 | 独立 SemVer | 启动器自更新（Tauri updater/自定义） | 较高 |
| `kernel` | Electron 壳 + fork DSH 运行时 | 独立 SemVer（壳与运行时同版本） | 启动器整包更新（非必要不更） | 低 |
| `plugin.<id>` | 每个音乐插件 npm 包 | 独立 SemVer | 启动器/插件管理器单独更新 | 中 |
| `service.<id>` | 每个 Python 后端服务 | 独立 SemVer | 启动器单独更新（带运行时依赖） | 中 |
| `tool.<id>` | ffmpeg/7z/VB-Cable/VST 等 | 独立版本 | 启动器单独更新 | 低 |
| `catalog.models` | 基础模型清单/下载索引 | 数据版本 | 启动器/网关更新 | 中 |
| `voices` | 用户音源 | **不更新** | 用户自备/自行替换 | — |

兼容规则：`kernel` 声明支持的插件 API 版本；每个插件声明 `engines.ams`/`engines.kernel`；启动器在更新前做兼容性校验，不兼容时阻止并提示。**内核更新必须保持“可选、可回滚、不阻塞插件更新”**。

**后端服务清单（首版）**：`ams-gateway`；`ams-svc-rvc-train`；`ams-svc-rvc-infer`；`ams-svc-vc`（实时音频 + RVC 推理）；`ams-svc-pymss`（分离）；`ams-svc-dataset`（ASR/对齐/质检）；`ams-svc-gptsovits`（TTS 微调/推理）；`ams-svc-tts-qwen`（零样本快捷，可合并）；`ams-svc-diffsinger`（P1）；`ams-svc-svs-zeroshot`（P1，可选）；`ams-svc-mixer`；`ams-svc-evaluator`；`ams-svc-msvc-convert`（Python 兜底；首选由启动器 Rust 内置转换）。

## 6. 音源库格式（强约束）

**唯一标准**：一个音源 = `voices/` 下的一个文件夹；文件夹内放**同名**的 `.pth` 与 `.index`：

~~~text
AMS_HOME\voices\
├─ 爱莉希雅\
│  ├─ 爱莉希雅.pth
│  └─ 爱莉希雅.index        # 可选；有则同名，无则视为“无检索增强”
└─ 曼波\
   ├─ 曼波.pth
   └─ 曼波.index
~~~

- 文件夹名即显示名/音源 ID（允许中文/空格；禁止 Windows 非法字符与首尾空格）；同名 pth/index 必须与文件夹名一致（不区分扩展名大小写）。
- `.pth` 必须能被 RVC v2 推理加载；启动器/音色库通过后端服务解析 `info/sr/f0/version/emb_g` 等元数据并缓存，不修改文件。
- `.index` 可选：无 index 仍可用（index_rate=0）；有 index 时校验维度（v2=768）并提示。
- 不要求必需的任何 JSON；应用可生成**可选**旁车 `voice.json`（标签/来源/许可备注/hash/解析缓存），删除它不影响使用；不得把必需信息只放在旁车里。
- **默认内置音源：曼波**（用户指定，经典且本机已有）。随安装包/首次启动离线资产包安装到 `voices/曼波/曼波.pth` + `曼波.index`，**不进 Git 仓库、不随源码分发**；插件默认音色 = 曼波；缺失时提示修复/重新安装。其余音源仍由用户自备。
- 除内置默认曼波外，音源不上传、不打包进 Git；应用只提供“打开音源目录/导入/校验/转换/重命名”等本地操作。
- TTS 与 SVS 的模型**不属于 RVC 音源库**：分别放 `tts_voices/`、`svs_voicebanks/`，在 UI 中作为独立“声库”分类；可手动关联同名 RVC 音源（同一角色多种用途）。

## 7. 工程（项目）格式

~~~text
AMS_HOME\projects\<project-id>\
├─ project.json          # 名称/创建时间/来源/目标音源/参数快照/版本
├─ source\               # 原始素材（音频/视频引用或副本，按设置）
├─ stems\                # 分离结果（vocals/instrumental/drums/bass/other...）
├─ vocals\               # 换声后的人声
├─ tts\                  # 配音片段
├─ singing\              # 填词/演唱结果
├─ mix\                  # 混音工程快照与导出
├─ eval\                 # 评测报告（HTML/JSON/CSV，评测器维护）
├─ exports\              # 成品（wav/flac/mp3）
└─ logs\                 # 本工程任务日志/参数
~~~
- `project.json` 由应用维护，记录每一步的输入/参数/产物/时间/使用的模型与音源版本，保证可复现与可回溯。
- 工程目录可整体移动/备份；音源与基础模型只存引用（名称+hash），不复制大文件。

## 8. 统一任务与 API 约定（Gateway）

所有耗时操作 = Job。插件、页面、启动器、CLI 都只通过 Gateway HTTP API 操作，不直接拉 Python。

**基础**：`http://127.0.0.1:<port>/api/v1`；Header `Authorization: Bearer <token>`；请求/响应 JSON；错误统一 `{ok:false, error:{code,message,detail?}}`。

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/health` | 网关与各服务状态 |
| GET | `/jobs` | 任务列表（按状态/类型/项目过滤） |
| POST | `/jobs` | 创建任务 `{type, params, project_id?}` |
| GET | `/jobs/{id}` | 任务详情（状态、进度、参数、产物、错误） |
| POST | `/jobs/{id}/cancel` | 取消（杀进程树） |
| GET | `/jobs/{id}/events` | SSE：progress/log/status/artifact 事件 |
| GET | `/jobs/{id}/artifacts` | 产物清单 |
| GET | `/artifacts/{id}/download` | 下载产物 |
| GET | `/catalog/...` | 模型/工具/音色库索引查询 |
| POST | `/voices/scan` `/voices/validate` | 音源库扫描/校验 |

**Job 对象**（必含）：`id`、`type`、`status`（queued/running/stopping/succeeded/failed/cancelled）、`progress`（0–100 + 阶段文字）、`params`、`project_id`、`created_at/started_at/finished_at`、`artifacts[]`、`error?`、`engine`（后端+版本）、`gpu_lock`。任务持久化到 SQLite，**网关重启后可查询历史；可恢复任务标记 resumable 并由后端断点续训**。

**任务类型注册表（v1.1，分册汇总后冻结；新增类型需回填本表）**：

| 任务类型 | 归属插件/组件 | 说明 |
|---|---|---|
| `dataset.import` / `dataset.slice` / `dataset.asr` / `dataset.align` / `dataset.clean` / `dataset.validate` / `dataset.export` | dataset | 数据集全流程；版本化快照 |
| `train.rvc` | trainer | RVC v2 训练（可续训） |
| `separate.pymss` | separator | 分离/去混响/去和声/多轨 |
| `convert.rvc` | song-convert | 离线换声（单文件/批量） |
| `convert.svc`（P1） | song-convert / singing | 零样本 SVC 换音色（SoulX-SVC） |
| `vc.session` | voice-changer | 实时长会话：不走 Job 队列，登记 GPU 独占租约 |
| `tts.generate` / `tts.batch` / `tts.train` / `tts.eval` | tts | 配音合成/批量/微调/评测 |
| `singing.prepare` / `singing.render` / `singing.export`（P1） | singing | 填词准备/渲染/导出 |
| `mix.render` | mixer | 多轨混音/响度/导出 |
| `eval.run` | evaluator | 客观/主观评测、A-B |
| `project.scan` / `project.backup` | project | 工程索引扫描/备份 |
| `msvc.convert` | launcher（+ Gateway 登记） | MSVC→pth 转换（启动器执行，Gateway 记录） |
| `tool.update` / `model.download` | launcher/gateway | 组件/模型下载（可选走 Job 以便统一进度） |


**GPU 锁**：同一时刻只允许一个显存型任务（训练/分离/换声/合成）；实时变声会话优先并独占；排队显示原因。CPU 任务可并行。

## 9. 插件规范

## 11. 更新系统约定

**更新中心**（启动器）分通道（stable/beta/dev），按组件展示：启动器 / 内核 / 各插件 / 各服务 / 工具 / 模型目录。每个组件可**独立勾选更新**。

**更新清单**（`ams-release` 仓库生成，HTTPS 分发）：
~~~json
{
  "schema": "ams-update/1",
  "channel": "stable",
~~~

## 12. 安全与隐私

- **本地优先**：默认不联网；联网仅用于模型/更新/用户显式触发的在线能力。
- **遥测关闭**：fork 内核中关闭 `session-log-deepseek`、`session-telemetry-otel`、产品埋点；启动器无遥测。隐私说明写明“无自动上传”。
- **密钥**：DeepSeek Key 只存 DSH 凭据文件（用户目录），不写日志、不上传；启动器不接触 key。
- **插件信任**：只安装签名/哈希匹配、来源 allowlist 的插件；开发模式需显式开启；插件声明权限并在首次使用时提示。
- **提权**：只有驱动/虚拟声卡/系统级工具安装请求管理员权限，且需用户确认；日常运行不提权。
- **下载校验**：所有下载校验 sha256；模型/音源导入校验文件类型与大小，自动执行前先预览。
- **AI 生成标识**：导出/发布时提供“AI 生成”元数据与文件名/ID3 可选标记。

## 15. 术语

| 术语 | 含义 |
|---|---|
| Kernel / 内核 | fork 后的 DSH 桌面应用（Electron 壳 + dsh 运行时） |
| Gateway | 本地任务/服务/产物网关（Python FastAPI） |
| Host 插件 | 运行在内核 Host 进程的 Node 插件（工具/服务/任务） |
| Client 插件 | 运行在 Web 客户端的 React 插件（页面/导航/组件） |
| 音源 | RVC v2 的 pth+index，放在 `voices/<名称>/` |
| 声库 | TTS 或 SVS 的模型包（`tts_voices/`、`svs_voicebanks/`） |
| Job | 一次耗时任务（训练/分离/换声/合成/评测…） |
| UVP | 统一音色包（本产品用作可选导入格式；主音源仍用文件夹格式） |

## 16. 已决策与仍待决策（v1.1）

### 16.1 已冻结的决策（来自各分册，后续开发以此为准）

| # | 决策 |
|---|---|
| 1 | **独立工作站**：自带内核（fork DSH），不依赖用户已装 DSH；启动器独立 Tauri2 应用。 |
| 2 | **fork 策略**：仓库 `yan-mc/ams-harness`，保留 upstream remote，最小 diff（品牌/构建/裁剪/组合/壳级契约）；业务代码 0 行进内核，全部在插件/服务。 |
| 3 | **内核组合**：profile=music，L1 dsh-base → L2 dsh-web-app → L3 @ams/music-bundle → L4 用户 patch → L5 home patch → L6 product.patch.yml。 |
| 4 | **音源格式**：严格 `voices/<名称>/<名称>.pth` + 同名 `.index`（可选）；**MSVC 转换只输出 .pth，不伪造 index**，无 index 明示 index_rate=0；TTS/SVS 声库独立目录。 |
| 5 | **MSVC 转换**：启动器内置，Rust 首选、Python 兜底；不提供 .cyd 解密，不内置分发权重；分片顺序推断需置信度与人工校验。 |
| 6 | **更新系统**：组件粒度（launcher/kernel/plugin.*/service.*/tool.*/catalog.models）；Ed25519+sha256+sequence+withdraw+min_launcher+mirrors；分模块勾选；内核非必要不更、可回滚；启动器自更新。 |
| 7 | **内核隐私/体积**：关闭 session-log-deepseek/telemetry/账号/内置 electron-updater；体积目标约 620–650 MB；内核包由启动器统一更新。 |
| 8 | **音频**：VB-Cable **不内置**（检测 + 官方下载引导）；ASIO 为 P1；官方 VST2/VST3 只做外链安装；GPL（pedalboard/matchering）默认不使用，必要时独立进程隔离。 |
| 9 | **新增目录**：`AMS_HOME/datasets/`（数据集快照）、`projects/<id>/eval/`（评测报告）、`backups/projects/`（工程备份）。 |
| 10 | **新增任务类型**：见第 8 节注册表（dataset.*、tts.*、singing.*、vc.session、project.scan/backup、msvc.convert 等）。 |
| 11 | **新增服务**：见第 5 节服务清单（rvc-train/rvc-infer/vc/pymss/dataset/gptsovits/tts-qwen/diffsinger/svs-zeroshot/mixer/evaluator/msvc-convert）。 |
