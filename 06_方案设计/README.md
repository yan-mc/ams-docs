> 版本：v1.1（2026-10-19 深夜）｜共 17 份文档 / 约 9,500 行｜全部为**文字方案**，不含产品代码。

## 1. 这是什么

这是“新时代开源 AI 音乐制作套件”的完整设计文档集：一个 **Windows 独立工作站**（不依赖现有 DSH 安装），由 **启动器 + fork 的 DSH 内核 + 音乐插件/页面 + Python 后端服务** 组成；AI（用户自接 DeepSeek Key）和人都能操作同一套功能。

范围覆盖：
- **启动器**：环境/组件/音源库/服务/模块化更新中心（launcher/kernel/每个插件/每个服务/工具）/MSVC→pth 转换器/诊断；
- **主体**：fork DSH、最小 diff、music profile/bundle、Host/Client 插件、页面、AI 集成、构建发布与内核更新；
- **插件（10 个）**：音源炼制、人声分离、变声器、歌曲换源、TTS/配音、数据集工作室、音色库、混音母带、评测器、项目管理（+ 填词成歌 P1）；
- **V 家填词**：P1 简略方案与资料存档（暂缓开发）；
- **工程与发布**：GitHub（yan-mc）备份/发布/签名/更新清单流程；**安装布局**（安装目录/AMS_HOME/默认曼波资产/后端 runtime/更新粒度与回滚）。

## 4. 关键设计一页纸

### 4.1 架构

~~~text
AMS Launcher (Tauri2)
  ├─ 环境/组件/服务/音源库/更新中心/诊断/MSVC 转换器
  └─ 拉起并监管 ── AMS Kernel（fork DSH + Electron）
                       ├─ music profile/bundle；Host 工具 + Client 页面 + Skills
                       └─ HTTP ── AMS Gateway（Python FastAPI）
                                     └─ 后端服务（各自 Python 运行时）
                                          rvc-train / rvc-infer / vc / pymss / dataset /
                                          gptsovits / tts-qwen / diffsinger(P1) /
                                          mixer / evaluator / msvc-convert
~~~

### 4.2 音源格式（强约束）

~~~text
AMS_HOME/voices/<名称>/<名称>.pth
                      <名称>.index   # 可选；无则 index_rate=0
~~~
TTS 放 `tts_voices/`，SVS 放 `svs_voicebanks/`，均与 RVC 音源库分离；**内置默认音源曼波**（随安装包/离线资产包，不进 Git），其余音源用户自备。

### 4.3 更新（启动器负责）

组件粒度：`launcher` / `kernel` / `plugin.<id>` / `service.<id>` / `tool.<id>` / `catalog.models`；可单独勾选更新。
Ed25519 + sha256 + sequence + withdraw + min_launcher + mirrors；下载→校验→暂存→快照→应用→健康检查→回滚。
**内核非必要不更新**（默认不自动；更新前快照、更新后兼容检查、失败回滚），但保留完整更新能力。

### 4.4 已冻结决策

见 `00_总体设计与约定.md` §16.1（14 条），包括：Tauri2 启动器、fork DSH、music profile/bundle、音源格式、MSVC 只输出 pth、模块化更新、VB-Cable 不内置、GPL 隔离、`datasets/` 与 `project/eval/` 目录、新增任务/服务/Skills、V 家 P1 暂缓等。

## 6. 下一步（建议）

按各分册的 M0 Spike 清单先验证高风险点，再进入编码：
1. **DSH 最小插件闭环**（Host tool+job / Client 整页 / 本地 HTTP 嵌入 / subprocess）；
2. **启动器更新链**（清单签名、暂存、回滚）与 **MSVC 转换器**（Rust 路径 + 另两个 .msvc 交叉验证）；
3. **pymss 分离 A/B**、**RVC 实时延迟**、**DiffSinger/SoulX/YingMusic 三路线试听**；
4. **统一音色库 + Gateway 任务**端到端（训练→导出→换声→混音→导出）。
